# 三尊・逆三尊 (Head and Shoulders / Inverse H&S)

## 概要

チャート分析で最も信頼性が高いとされる**反転パターン**のひとつ。
三尊（Head and Shoulders Top）は**天井圏**、逆三尊（Inverse H&S）は**底値圏**で形成される。

- **三尊**: 上昇トレンドの終焉 → 下降トレンドへの転換シグナル
- **逆三尊**: 下降トレンドの終焉 → 上昇トレンドへの転換シグナル

---

## 三尊（天井反転）

### 形状

```
              Head（頭）
             /    \
  LS        /      \        RS
(左肩)     /  (頭)  \    (右肩)
   /\      /          \    /\
  /  \    /            \  /  \
 /    \  /              \/    \
/      \/                      \
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ ← ネックライン
```

| 部位 | 特性 |
|------|------|
| 左肩（LS: Left Shoulder）| 上昇トレンドの最後の高値の一つ前 |
| 頭（Head）| 最も高い高値。ここで新高値を更新するが勢いは弱い |
| 右肩（RS: Right Shoulder）| 頭より低い高値。ここが「上昇トレンド終了」の証拠 |
| ネックライン | 左肩安値と頭の後の安値を結んだライン |

### 形成プロセスとモメンタムの変化

```
① 左肩の高値: 上昇が続いてきた。まだトレンド継続に見える
② 頭の高値: 新高値更新。しかしここで「買い疲れ」が始まる
   → RSIが高値を更新しない（弱気ダイバージェンス）ことが多い
③ ネックラインへの下落: 一旦売り圧力が入る
④ 右肩の反発: 反発するが頭に届かない。買い手の弱さが露呈
⑤ ネックラインブレイク: 三尊完成。売りシグナル発動
```

---

## 逆三尊（底値反転）

三尊を上下逆にした形。

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ ← ネックライン
\      /\                      /
 \    /  \              /\    /
  \  /    \            /  \  /
   \/      \          /    \/
  (左肩)    \        /    (右肩)
              \      /
               \ (頭)/
                \  /
              Head（頭）
```

| 部位 | 特性 |
|------|------|
| 左肩 | 下落トレンドの後半、最後から2番目の安値 |
| 頭 | 最も低い安値 |
| 右肩 | 頭より浅い安値。下落モメンタムの低下を示す |
| ネックライン | 左肩高値と頭後の高値を結んだライン |

---

## ネックライン

### ネックラインの特定

- **水平のネックライン**: 左肩後の安値と頭後の安値がほぼ同じ高さ → 最もシンプルで機能しやすい
- **右肩上がりのネックライン**: 強気の三尊。下落の勢いが弱いことを示す
- **右肩下がりのネックライン**: 弱気の三尊。下落の勢いが強い

### ブレイクの条件
- 終値でネックラインを明確に抜ける
- 出来高の増加があれば信頼性UP（株・先物では特に）

---

## 目標値の計算

```
三尊の目標値 = ネックライン - (頭の高値 - ネックライン)

例:
  頭の高値: 115.00
  ネックライン: 112.00
  距離: 115.00 - 112.00 = 3.00 円
  
  目標値: 112.00 - 3.00 = 109.00
```

逆三尊は逆方向に同じ計算。

**注意**: 目標値はあくまで「最低限の目標」。途中の水平線やフィボレベルで止まることも多い。

---

## トレードへの応用

### エントリー方法

**方法1: ネックラインブレイクでエントリー（積極的）**
```
ネックラインを終値で抜けた直後にエントリー
→ 早めに乗れるが、ダマシのリスクあり
```

**方法2: リテストを待つ（保守的・推奨）**
```
ネックラインブレイク後、一旦ネックラインまで戻る動き
→ 旧サポート（ネックライン）が今度はレジスタンスとして機能
→ そこで反発を確認してエントリー
→ ダマシが減る代わりにエントリーを逃すリスクあり
```

**SL の設定**
- 三尊の場合: 右肩の高値の上
- 逆三尊の場合: 右肩の安値の下

---

## 品質の良いパターンの特徴

| 要素 | 理想的な状態 |
|------|------------|
| 左肩と右肩の高さ | ほぼ対称（±10%程度） |
| 左肩と右肩の幅 | 対称。時間も似ている |
| 出来高 | 頭 > 左肩 > 右肩（だんだん減る）|
| ネックライン | 水平に近い |
| ブレイク時の出来高 | 増加 |

---

## よくある失敗パターン・注意点

### 右肩でのエントリー（早すぎ）
```
頭の後に下落 → 反発して右肩形成中
→「もう天井確認した」としてショートエントリー
→ 実は右肩が終わっておらず、さらに上に行く
→ ネックラインブレイクまで待つのが原則
```

### 目標値を鵜呑みにする
目標値計算はあくまで参考。途中の強い水平線で止まることがある。

### 変形パターン
- **複合型三尊**: 肩が2つずつある（拡張版）
- **傾いたパターン**: 全体が右肩上がり or 右肩下がり

---

## RSI・MACDとの組み合わせ

三尊・逆三尊の信頼性を上げる最大の確認材料:

```
三尊の場合:
  頭の高値 > 左肩の高値 （価格は新高値）
  RSI の高値 < 左肩時のRSI （弱気ダイバージェンス）

→ 両方揃えば「モメンタムが枯渇した天井」として非常に信頼性が高い
```

---

## フォレックスでの使い方

- **日足・4H足**での三尊・逆三尊が特に信頼性が高い
- ネックラインのブレイクは**FXの重要水準（ラウンドナンバー等）** と重なると強い
- 目標値計算をフィボナッチエクステンションで補強

---

## まとめ

> 三尊・逆三尊はチャートパターンの中で「教科書的」に語られるが、
> 実際に機能する理由は明確: **頭でトレンドの勢いが衰え、右肩でその失速が確認される**。
> ネックラインのブレイクは「以前の安値を割った」という事実であり、
> トレンド転換の構造的な証明になる。
> 最重要なのは**右肩での弱気ダイバージェンス確認 + ネックラインブレイク**のセット。

---

## 実例：実チャートベースのトレード例

### 例1: EUR/USD 週足 — 三尊天井が2021〜2022年の下落を予告

**状況**  
2020〜2021年、EUR/USDは1.23〜1.24台まで上昇した後、週足で明確な三尊（H&S）を形成。この大型パターンのブレイクが2022年の大幅下落の起点となった。

**パターンの形状**
```
左肩: 2021年1月 高値 1.2350
頭 : 2021年5月 高値 1.2265（左肩より低い場合もある）
右肩: 2021年10月 高値 1.1910

ネックライン: 1.1600付近（左肩・頭後の安値を結んだ線）

RSI確認:
  左肩時: RSI 72
  頭 時: RSI 68  ←弱気D（価格差小、RSI差あり）
  右肩時: RSI 58  ←さらに切り下げ、明確な弱気D
```

**トレード**
```
2021年11月〜12月: ネックライン（1.1600）を終値でブレイク
リテスト（2022年1月）: 1.1500付近まで一時戻し → 陰線確定
→ ショートエントリー
```

| 項目 | 値 |
|------|-----|
| エントリー | 1.1480（リテスト後の週足陰線確定）|
| SL | 1.1750（右肩高値の上）|
| TP | 1.0200（目標値計算: 1.1600 - (1.2350-1.1600)）|
| 結果 | 9月に0.9536まで下落。目標を大幅に超えた |
| RR比 | 約1:4.8（TP到達時点）|

**ポイント**  
週足の大型三尊は形成に1〜2年かかるため、見つけた時点でかなり大きなトレンド転換のシグナル。右肩でのRSI三段階の弱気ダイバージェンスが「絵に描いたような」パターンだった。

---

### 例2: USD/JPY 日足 — 逆三尊が2023年の上昇を示唆（2023年1〜3月）

**状況**  
2022年10月の高値151.94から2023年1月の安値127.23まで下落したUSD/JPY。その後、日足で逆三尊（Inverse H&S）が形成され、上昇転換のシグナルを発した。

**パターンの形状**
```
左肩: 2022年11月安値 137.67
頭 : 2023年1月安値  127.23  ← 最も低い安値
右肩: 2023年3月安値  129.64  ← 頭より高い = 売りモメンタム低下

ネックライン: 137.00〜138.00付近

RSI確認:
  左肩時: RSI 30付近
  頭 時: RSI 24付近  ←過売れ
  右肩時: RSI 32付近  ←強気D（価格は頭より高くRSIも改善）
```

**トレード**
```
2023年5月: ネックライン（137.50）を日足終値でブレイク
→ 直後にロングエントリー（リテスト待たず積極的に）
リテスト（5月末）: 137.00付近まで押し → 反発確認
```

| 項目 | 値 |
|------|-----|
| エントリー | 137.80（日足ブレイク確定翌日）|
| SL | 135.50（右肩安値の下）|
| TP計算 | 137.00 + (137.00 - 127.23) = 約146.80 |
| 結果 | 11月に151円台まで上昇。目標超え |
| RR比 | 1:4以上 |

**ポイント**  
逆三尊は下降トレンドの底値圏で形成されるが、「右肩が頭より浅い」という構造が売りモメンタムの枯渇を証明している。ネックラインブレイクは「高値更新 = 上昇トレンド再開」の確認でもある。

### 例3: AUD/USD 4H足 — 三尊形成後の速いブレイクと急落（2023年2月）

**状況**  
2023年2月、AUD/USDが0.71台付近で4H足の三尊を形成した後、急落した局面。短い時間軸でも三尊パターンは機能する。

**パターンの形状**
```
左肩: 0.7130（2023年2月初旬高値）
頭 : 0.7160（数日後の高値、わずかに更新）
右肩: 0.7100（左肩より低い → 明確な弱さ）

ネックライン: 0.6980〜0.7000付近

形成期間: 約3週間
```

**トレード**
```
右肩を確認した時点で「三尊かもしれない」と注目
ネックライン（0.6990）を4H足終値で下抜け確認
→ ショートエントリー

SL: 0.7050（右肩高値の上）
TP: 0.6990 - (0.7160 - 0.6990) = 0.6820
```

| 項目 | 値 |
|------|-----|
| エントリー | 0.6980（ブレイク確定の次の4H足）|
| SL | 0.7050 |
| TP | 0.6820 |
| 結果 | 2週間後に0.6580まで下落。目標大幅超え |
| RR比 | 約1:2.3（TP到達時点）、実際はさらに大きい |

**ポイント**  
短い時間軸（4H）の三尊でも基本的な構造は同じ。「右肩が左肩より低い」という点に注目。ここではさらにRBIの利上げ打ち止め観測というファンダメンタルズの変化が後押ししたケースだが、テクニカルだけでもパターンとして完結していた。

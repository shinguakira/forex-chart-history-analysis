# 水平線・サポート＆レジスタンス (Support & Resistance)

## 概要

チャート上の「価格が何度も反発する水平のライン」。テクニカル分析の最も基礎的かつ最も重要な概念。すべてのインジケーターや手法は、最終的にこの水平線の文脈の中で機能している。

---

## サポートとレジスタンスの定義

### サポート（支持線）
価格が下落してきた時に「支えられる」水準。

```
過去に: 価格が何度かそのレベルで反発して上昇した
→ 下落してきた時に再び買い需要が入りやすい
```

### レジスタンス（抵抗線）
価格が上昇してきた時に「止められる」水準。

```
過去に: 価格が何度かそのレベルで上昇が止まった
→ 上昇してきた時に再び売り圧力が入りやすい
```

---

## ロール：サポレジの役割交代

最も重要な概念のひとつ。

### レジスタンスがブレイク → サポートに転換

```
━━━━━━━━━━━━━━━━ ← 過去のレジスタンス
価格が何度も弾かれていた
         ↓
ブレイクアウト
         ↓
━━━━━━━━━━━━━━━━ ← 今度はサポートとして機能
価格が下落して戻ってきたときに反発
```

### サポートがブレイク → レジスタンスに転換

```
━━━━━━━━━━━━━━━━ ← 過去のサポート
価格が何度も反発していた
         ↓
ブレイクダウン
         ↓
━━━━━━━━━━━━━━━━ ← 今度はレジスタンスとして機能
価格が上昇して戻ってきたときに弾かれる
```

このロール（役割交代）がリテストとして機能し、ブレイクアウトトレードの根拠となる。

---

## 強いサポレジの条件

### 1. タッチ回数
```
2回反発 < 3回反発 < 4回以上反発
→ タッチ回数が多いほど多くの参加者が意識している
```

### 2. 時間足の高さ
```
週足・月足 >> 日足 >> 4H > 1H > 15M
→ 上位足のS/Rは下位足のノイズに飲まれない
```

### 3. 反発の強さ
```
急反発（長いヒゲ、大きなキャンドル）があったレベル
→ その価格帯での需給のアンバランスが強い証拠
```

### 4. 長期間機能しているレベル
```
1年以上前に機能したレベルが再び機能する例は珍しくない
→ 古い水平線も消さずに残しておく価値がある
```

### 5. ラウンドナンバー（キリ番）

```
例: USD/JPY なら 110.00, 115.00, 150.00
    EUR/USD なら 1.1000, 1.2000, 1.3000
```

心理的節目。自動注文（指値・逆指値）が集中しやすく、機能しやすい。

---

## ゾーンとして見る

価格は点でなく「幅」で動く。水平線を「ライン」ではなく**「ゾーン」**として捉える。

```
例: 110.00 の水平線 → 109.80〜110.20 のゾーン

理由: 
  - スプレッドの存在
  - ヒゲで少し超えることがある（オーバーシュート）
  - 参加者によって微妙に認識するレベルが違う
```

**実践**: ゾーンに入ったら警戒開始、ゾーンの中心付近でエントリーを検討。

---

## 水平線の引き方

### 何を基準にするか

| 基準 | 特性 |
|------|------|
| **ヒゲ先端** | 最大の値幅の動き。マーケットが最大限試みた価格 |
| **実体の上下端** | より「確実に」機能した価格帯 |
| **終値** | 最終的に参加者が合意した価格 |

どれが正解というわけではなく、ゾーンを意識しつつ複数本のヒゲが集まるエリアを使う。

### 実践的な引き方

1. 週足・日足で「明らかに反応した価格帯」を先に特定
2. 4H 足に落として微調整
3. 直近の高値・安値だけでなく、**古い高値・安値**も残す
4. 引きすぎない（5本以上引くとチャートが汚れて判断できなくなる）

---

## マーケットメーカーの視点

水平線の「もう少し先」に多くの注文が集まっていることを機関投資家は知っている。

```
明らかな水平線の上方 → 多くのロングの逆指値（SL）が集まっている
明らかな水平線の下方 → 多くのショートの逆指値（SL）が集まっている
```

→ 水平線を少し超えて（**ストップ狩り**）から反転するパターンが頻繁に発生。
→ ちょうどのラインにストップを置くより、**少し余裕を持たせたゾーンの外側**にストップを設定する。

---

## フォレックスでの使い方

### サポートでの押し目買い
```
1. 上位足（日足）のサポートを特定
2. 下位足（1H）で価格がサポートに近づくのを待つ
3. サポートゾーンで陽線確定 or ピンバー出現
4. エントリー
5. SL: サポートゾーンの少し下
6. TP: 次の重要なレジスタンス
```

### ブレイクアウト＋リテスト
```
1. レジスタンスをブレイク
2. 一旦離れる
3. 戻ってきてレジスタンス（今度はサポート）でリテスト
4. そこで陽線・ピンバー確認
5. ロングエントリー
```

リテストがないままの「素のブレイク」は失敗（ダマシ）が多いため、
**リテストを待つのが基本**。

---

## 主要なS/Rの種類

| 種類 | 特性 |
|------|------|
| 水平線 | 最も基本。過去の高値・安値 |
| フィボナッチレベル | 数学的なS/R候補 |
| 移動平均線（200MA等）| ダイナミックなS/R |
| トレンドライン | 斜めのS/R |
| 心理的節目（キリ番）| ラウンドナンバー |
| 前日高値・安値（PDH/PDL）| デイトレで重要 |
| 週の高値・安値（PWH/PWL）| スイングで重要 |

---

## 限界・注意点

- **明確に機能するかは結果論**: 事前に「ここで絶対止まる」とは言えない
- **引きすぎは禁物**: チャートを水平線だらけにすると判断が麻痺する
- **ゾーンの幅の判断が難しい**: 広すぎると精度が落ち、狭すぎると機能しなくなる
- **ブレイクとダマシの区別**: 一時的に超えただけなのか、真のブレイクなのかの判断が難しい

---

## まとめ

> 水平線は「チャートの骨格」。
> すべてのエントリーは「S/Rに対してどの位置にいるか」で評価される。
> インジケーターがどんなシグナルを出していても、重要な水平線付近での動きは
> その後の価格行動を大きく左右する。
> **まず水平線を引いてから、その上でシグナルを判断する**というプロセスが基本。

## 実例：実チャートベースのトレード例

### 例1: USD/JPY 日足 — 145円が介入ラインとしてレジスタンス→サポートにロール（2022〜2023年）

**状況**  
2022年9月に日本政府・日銀がUSD/JPYの145円超えで初の為替介入を実施。その後この145円ラインが「介入の目安」として市場参加者全員に強く意識されるようになり、何度もS/Rとして機能した。

**水平線のロールの流れ**
```
①2022年9月: 145円を上抜け → 介入で急落
  → 145円はレジスタンスとして認識

②2022年10月: 145円を再度上抜け → 再介入で急落
  → 145円の壁が再確認される

③2022年10月末〜11月: 145円を下回った状態が続く
  → 今度は145円がレジスタンスとして機能（戻り売りゾーン）

④2023年5月: 価格が再び145円に到達
  → 今度は上方向に突破（ロール完了）
  → 145円がサポートに転換

⑤2023年6月: 145円付近への押し目
  → サポートとして反発 → ロングの機会
```

| 項目 | 値 |
|------|-----|
| エントリー | 145.20（145円サポートでの4H陽線確定）|
| SL | 143.80（145円を明確に割り込む下）|
| TP | 150.00（次の大台）|
| 結果 | 11月に151円台到達。大幅TP超え |
| RR比 | 約1:3.4 |

**ポイント**  
「介入ライン」という外的イベントが水平線に強烈な意味を与えた例。このように「なぜその価格が意識されるか」の背景を理解することで、単なるテクニカルより強い根拠を持てる。

---

### 例2: EUR/USD 日足 — 1.0000（パリティ）でのロール（2022年7〜11月）

**状況**  
EUR/USDのパリティ（1.0000）は2002年以来20年ぶりの水準で、心理的・歴史的に極めて重要なラウンドナンバー。2022年7月に割り込み、9〜11月は何度もこのレベルをテストした。

**価格の動き**
```
2022年7月上旬: パリティを初めて下抜け（20年ぶり）
  → 多くの逆張り勢が「1.0000で買いたい」注文を入れていた
  → 実際はすり抜けて0.9900まで下落（ストップ狩り）

2022年8月: 1.0100まで反発
  → パリティ（1.0000）がレジスタンスとして機能
  → 戻り売りの機会

2022年9月〜10月: 0.9700〜0.9900でレンジ
  → パリティは常にレジスタンスとして天井

2022年11月: パリティを上抜けてロール
  → 今度はサポートとして機能
  → 1.0000への押し目でのロングが機会
```

| 項目 | 値 |
|------|-----|
| エントリー | 1.0020（パリティ上抜け確定後の押し目）|
| SL | 0.9880 |
| TP | 1.0500 |
| 結果 | 12月に1.0600到達。TP達成 |
| RR比 | 約1:3.4 |

**ポイント**  
「20年ぶりのパリティ」というニュース性のあるラウンドナンバーは特に機能しやすい。ただし最初の「チャレンジ」では必ずと言っていいほどストップ狩りで少し突き抜けてから反転するため、ぴったりのラインではなくゾーンで管理することが不可欠。

---

### 例3: USD/JPY 日足 — 130円ブレイク後のリテスト（2022年4〜5月）

**状況**  
2022年4月末、USD/JPYが約20年ぶりに130円台に乗せた。歴史的に重要なラウンドナンバーである130円がブレイク後にサポートに転換し、リテストで買いの機会が生まれた。

**価格の動き**
```
2022年4月28日: 130.00を初めて上抜け（終値131.00）
  → 「130円のブレイク」として大きく報道

2022年5月上旬: 一時126円台まで押し目
  → この時点では130円に戻っていない（リテストではなく深い押し）

2022年5月下旬: 130円付近まで戻る
  → 旧レジスタンス130円がサポートとして機能
  → 4H足で長い下ヒゲ + 陽線確定

→ リテストでのロングエントリー機会
```

| 項目 | 値 |
|------|-----|
| エントリー | 130.30（4H陽線確定）|
| SL | 128.50（130円を明確に割り込む水準）|
| TP① | 135.00 |
| TP② | 140.00 |
| 結果 | 6月に135円到達。TP①達成後も上昇継続 |
| RR比 | 1:2.6（TP①）|

**ポイント**  
歴史的なブレイクポイント（20年ぶりの130円）は特に「ロール」が機能しやすい。多くの参加者がこのレベルを覚えており、「押したら買い場」という行動を取る人が増えるため、自己成就予言的にサポートが機能する。

# EMA (Exponential Moving Average / 指数移動平均)

## 概要

直近のデータに大きな重みを置いた移動平均。SMAに比べて**価格変動への反応が速い**。MACDや多くのシステムトレードの基礎となる。

---

## 計算式

```
EMA(今日) = 前日EMA + α × (今日の価格 - 前日EMA)
```

**平滑化係数 α（アルファ）:**
```
α = 2 / (n + 1)
```

- n=12の場合: α = 2/13 ≈ 0.1538
- n=26の場合: α = 2/27 ≈ 0.0741

**初期値**: 最初のn本のSMAをEMAの初期値として使う。

### 展開するとわかること

```
EMA = α×P₀ + α(1-α)×P₋₁ + α(1-α)²×P₋₂ + ...
```

過去に遡るほど重みが指数関数的に減少する（だから"指数"移動平均）。
最新データが最も重く、古いデータの影響が徐々に薄れる。

---

## SMAとの重みの比較（n=10の場合）

| バー前 | EMA の重み | SMA の重み |
|--------|------------|------------|
| 0（最新）| 18.2% | 10% |
| 1 | 14.9% | 10% |
| 2 | 12.1% | 10% |
| 5 | 5.3% | 10% |
| 10 | 1.5% | 10% |
| 20 | 0.1% | 0% |

EMAは最新の動きを重視するため、トレンド転換の**検知が早い**。

---

## 主要な期間設定

| 期間 | 主な用途 |
|------|----------|
| 8 | 超短期スキャルプ |
| 12 | MACDの短期線 |
| 20 | 短中期トレンド |
| 26 | MACDの長期線 |
| 50 | 中期トレンド |
| 200 | 長期トレンド（SMAほど注目されないが使われる） |

---

## 読み方

### 1. 傾きとトレンド
SMAと同じだが、EMAのほうが早く傾きが変わる。

### 2. EMAリボン
複数のEMAを重ねて表示するテクニック。
```
EMA(8) > EMA(21) > EMA(55) > EMA(144)
  → 全部同方向に並んでいれば強いトレンド
  → 絡み合っていればレンジ or 転換中
```

### 3. 価格とのかい離

価格がEMAから大きく離れると**平均回帰**の力が働きやすい。
- 急上昇後にEMAから離れすぎた価格 → 押し目を待つ
- 急落後にEMAから離れすぎた価格 → 戻り売りを待つ

---

## EMA vs SMA：どちらを使うか

| 比較軸 | EMA | SMA |
|--------|-----|-----|
| 反応速度 | 速い | 遅い |
| ラグ | 小さい | 大きい |
| ノイズへの感度 | 高い（誤シグナル増）| 低い（安定） |
| 向いている相場 | トレンド相場、スキャルプ | スイング、長期 |
| 広く意識されるレベル | やや少ない | 200SMAが特に強い |

**実践的な結論**:
- 短期トレード → EMA（反応速度優先）
- フィルター・大局判断 → SMA（特に200SMA）
- MACDなど計算に組み込む場合 → EMA（設計上の標準）

---

## フォレックスでの使い方

### スキャルプ・デイトレ
EMA(8)/EMA(21) の並び順でバイアスを決め、押し目・戻りでエントリー。
```
EMA8 > EMA21 → 押し目買い（EMA8付近）
EMA8 < EMA21 → 戻り売り（EMA8付近）
```

### トレンドフォロー（3本EMA）
```
EMA(20) > EMA(50) > EMA(200) → 買いのみ
EMA(20) < EMA(50) < EMA(200) → 売りのみ
```

### ダイナミックS/R
特に21EMAと55EMAがスイングトレーダーに人気。
価格がEMAに戻ってきた時の「反発か突破か」がエントリー判断になる。

---

## 限界・注意点

- **初期値の影響**: 計算開始直後はデータが少ないため不正確。十分なバー数が必要
- **ウィッピング**: レンジ相場でEMAを価格が行ったり来たりし、誤シグナルが多発
- **最適期間はない**: どの期間も「後から見れば最適」はあるが、未来には通用しないことが多い
- **SMAより認知度が低いレベル**: 200SMAほど広く意識されるEMAレベルは少ない

---

## まとめ

> EMAはSMAより「今」の動きに敏感。
> トレンドの初動を早く捉えたい・スキャルプや短期売買に向く。
> ただしノイズにも敏感なため、**上位足のフィルターと組み合わせること**が前提。
> MACDの構成要素としても必須の知識。

## 実例：実チャートベースのトレード例

### 例1: USD/JPY 1H足 — EMA21がダイナミックサポートとして機能（2022年4〜5月）

**状況**  
2022年4月、USD/JPYが130円を20年ぶりに突破した直後。強い上昇モメンタムの中、1H足のEMA21が「押し目のターゲット」として繰り返し機能していた。

**シグナルと判断**
- 1H足EMA21が右上がり（130〜131円付近）
- 価格が急騰 → EMA21に引き戻される → 反発を繰り返すパターン
- 日足は200SMAより大幅上。売りバイアスはなし
- 押し目でのピンバーや陽線の包み足が確認できる

**具体的な局面**
```
131.00まで急騰
  ↓
EMA21（130.20付近）まで押し目
  ↓
1H足で陽線ピンバー確定
  → ロングエントリー
```

| 項目 | 値 |
|------|-----|
| エントリー | 130.30（EMA21タッチ後の陽線確定）|
| SL | 129.70（EMA21の少し下）|
| TP | 132.00（直近高値付近）|
| 結果 | 翌日131.80で利確（ほぼTP到達）|
| RR比 | 約1:2.8 |

**ポイント**  
強いトレンド中の1H足EMA21押し目は最も再現性の高いパターンの一つ。「急騰→EMA引き戻し→反発」のサイクルを繰り返す局面では、EMA21タッチごとにエントリー機会が来る。

---

### 例2: EUR/USD 4H足 — EMAリボン崩壊でトレンド転換を確認（2022年2〜3月）

**状況**  
2022年2月後半、EUR/USDがロシアによるウクライナ侵攻でリスクオフ・ドル高に傾く局面。1.1300台にいた価格が急落し始め、EMAリボンが崩壊した。

**シグナルと判断**
- 4H足: EMA8、EMA21、EMA55が1.1100付近で「デスリボン」（短期が長期を下抜け）
- EMA8 < EMA21 < EMA55 の順に並び揃った → 強い下降バイアス確定
- その後の戻りはEMA21（レジスタンス）で止まり続けた

**トレード（リボン崩壊後の戻り売り）**
```
EMA21（1.0950付近）まで戻り
  → 4H足で陰線包み足
  → EMA8がEMA21を上から割る確認
  → ショートエントリー
```

| 項目 | 値 |
|------|-----|
| エントリー | 1.0930（4H陰線確定）|
| SL | 1.1020（EMAリボン全体の上）|
| TP① | 1.0500（心理的節目）|
| TP② | 1.0000（パリティ）|
| 結果 | 7月にパリティ到達。TP②達成 |
| RR比 | 1:4以上 |

**ポイント**  
「EMAリボンが完全に並び替わった」瞬間は、複数の時間足が同じ方向を向いたサインでもある。このシグナルは遅いが確実性が高く、そこからのトレンドが長期間続くことが多い。

---

### 例3: GBP/USD 1H足 — 急落後EMA8/21クロスで反転エントリー（2022年10月）

**状況**  
2022年9月末、英国ミニ予算ショックでGBP/USDが1.0349まで急落。その後10月に急速に回復する局面。1H足でEMA8がEMA21を上抜けした後、押し目が来た。

**シグナルと判断**
- 1H足: EMA8がEMA21を下から上に明確にクロス（1.1000付近）
- クロス後の押し目でEMA21（1.1050付近）がサポートとして機能
- 上位足（4H）も200SMAより大幅下だが、日足でRSI強気ダイバージェンス発生中
- 短期的な上昇トレンド（リバウンド）として割り切ってトレード

| 項目 | 値 |
|------|-----|
| エントリー | 1.1060（EMA21タッチ後の1H陽線確定）|
| SL | 1.0950（直近安値の下）|
| TP | 1.1400（4H足の直近レジスタンス）|
| 結果 | 1.1400到達、利確 |
| RR比 | 約1:3.1 |

**ポイント**  
EMAクロスは「方向が変わった確認」として使い、クロス後の最初の押し目でエントリーするのが正しい使い方。クロスの瞬間に飛び乗るより、引き付けてからエントリーすることでSLを小さくできる。

# チャートパターン集 (Chart Patterns)

フラッグ・ペナント・ウェッジ・トライアングル・カップ&ハンドルなど、
三尊・ダブルトップ以外の主要なチャートパターンをまとめる。

---

## パターンの分類

| 種類 | 意味 | 代表パターン |
|------|------|------------|
| **継続パターン** | トレンドが一休みして再開する | フラッグ、ペナント、対称トライアングル |
| **反転パターン** | トレンドが転換する | ウェッジ（一部）、拡大フォーメーション |
| **どちらにも** | ブレイクの方向によって決まる | 対称トライアングル、ウェッジ |

---

## フラッグ (Flag) ─ 継続パターン

急激な動き（ポール）の後、逆方向に緩やかに押し戻されるパターン。
旗竿（ポール）に旗（フラッグ）が付いた形。

### 形状

```
上昇フラッグ:
        ───────
       /  \ /  \   ← フラッグ（やや下向きのチャンネル）
      /    /    \
     /    /      \──
    /    /
---/  ← ポール（急上昇）
```

```
下降フラッグ:
---\  ← ポール（急下落）
    \    \
     \    \      /──
      \    \    /
       \  / \  /   ← フラッグ（やや上向きのチャンネル）
        ───────
```

### 特性

- フラッグは**トレンド方向と逆向きに緩やかに**推移する（逆方向ならOK）
- ポールの長さが目標値の目安
- **出来高**: ポールで増加 → フラッグで減少 → ブレイクで再増加 が理想

### 目標値

```
目標値 = ブレイクポイント + ポールの長さ
```

### トレード

```
① ポール（急騰/急落）を確認
② フラッグ形成を確認（逆方向のチャンネル）
③ フラッグのブレイクを待つ
④ エントリー
⑤ SL: フラッグの反対辺の外側
⑥ TP: ポールの長さ分
```

---

## ペナント (Pennant) ─ 継続パターン

フラッグと同様にポール+フラッグだが、フラッグ部分が三角形（ペナント）になる。

### 形状

```
上昇ペナント:
       /\
      /  \
     / 収 \
    /  縮  \→→ ブレイクアウト
   /         \
--/  ← ポール  \...(収縮する三角形)
```

### フラッグとの違い

| 比較 | フラッグ | ペナント |
|------|--------|---------|
| フラッグ部分の形 | 平行チャンネル | 収縮する三角形 |
| 継続時間 | 短め | やや短め |
| 出来高パターン | 同じ | 同じ |

---

## ウェッジ (Wedge) ─ 反転 or 継続

2本の収縮する傾いたトレンドラインの間に価格が挟まれるパターン。

### 上昇ウェッジ（ライジングウェッジ）

```
        /──────  ← 上辺（傾き緩い）
       /    /
      /    /
     /    /
    /    /
   /──── ← 下辺（傾き急）
```

- **逆張りシグナル（下落）**: 上昇しているが収縮している = 買い圧力が徐々に弱まっている
- 上昇トレンド中 → 反転（天井）
- 下降トレンド中の戻り → 継続（戻り売り）

### 下降ウェッジ（フォーリングウェッジ）

```
\──── ← 上辺（傾き急）
 \    \
  \    \
   \    \
    \    \
     \────  ← 下辺（傾き緩い）
```

- **順張りシグナル（上昇）**: 下落しているが収縮している = 売り圧力が弱まっている
- 下降トレンド中 → 反転（底値）
- 上昇トレンド中の押し目 → 継続（押し目買い）

### まとめ

| ウェッジ | トレンド中 | 意味 |
|---------|-----------|------|
| 上昇ウェッジ | 上昇中 | 天井反転の可能性（売り） |
| 上昇ウェッジ | 下落中の戻り | 継続（戻り売り） |
| 下降ウェッジ | 下落中 | 底値反転の可能性（買い） |
| 下降ウェッジ | 上昇中の押し目 | 継続（押し目買い） |

## トライアングル (Triangle)

3種類。方向感が異なる。

### 1. 対称トライアングル（Symmetrical Triangle）

```
   /\ /\ /\
  /  V  V  \──→ どちらにブレイクするか不明
 /          \
/   収縮     \
```

- 高値が切り下がり、安値が切り上がり → 上辺・下辺が収縮
- **ブレイクの方向がわからない** → ブレイクを確認してからエントリー
- 多くの場合、トレンド継続パターンとして機能

### 2. 上昇トライアングル（Ascending Triangle）

```
━━━━━━━━━━━━━━━━ ← 水平な上辺（同じ高値で何度も止まる）
   /\ /\ /\
  /  V  V  V──→ ブレイクアップ（買いシグナル）
```

- 高値は同レベルで押さえられているが、安値は切り上がっている
- 買い手が売り手に着実にプレッシャーをかけている
- **強気パターン**: 上にブレイクしやすい

### 3. 下降トライアングル（Descending Triangle）

```
   /\ /\ /\──→ ブレイクダウン（売りシグナル）
  /  V  V  V
 /          
━━━━━━━━━━━━━━━━ ← 水平な下辺（同じ安値で何度も支えられる）
```

- 安値は同レベルで支えられているが、高値は切り下がっている
- 売り手が買い手を着実に追い詰めている
- **弱気パターン**: 下にブレイクしやすい

### 目標値

```
ブレイクポイント ± トライアングルの最大幅（一番左端の幅）
```

## カップ＆ハンドル (Cup & Handle)

ウィリアム・オニールが提唱した上昇継続パターン。

### 形状

```
        ━━━━━━━━━━━━ ← ネックライン
       /    ハンドル\   /
      /    (/\)     \ /──→ ブレイクアップ
     /     /  \      ∨
    /    (cup)  \
   /              \
  /    U字底       \
 ─────────────────────
```

### 形成プロセス

```
① カップ（U字の底）:
   - 急落後、緩やかに下値を切り上げながら戻ってくる
   - V字（急反発）より U字（緩やか）の方が理想的
   - 期間は数週間〜数ヶ月

② ハンドル:
   - ネックライン付近に戻ってきた後、小さな押し戻し
   - 出来高が減少するのが理想
   - 全体の20〜30%を超えない浅い押し戻し

③ ブレイクアウト:
   - ネックラインを出来高増加とともに抜ける
   - エントリーポイント
```

### 目標値

```
カップの深さ = ネックライン - カップの底値
目標値 = ネックライン + カップの深さ
```

---

## 拡大フォーメーション（メガフォン）

トライアングルの逆。高値が切り上がり、安値が切り下がる。

```
   /\ /\ /\──→ 拡大
  /  V  V  V
```

- 不確実性・混乱の高まりを示す
- 多くの場合、**天井圏**で見られる（反転パターン）
- ボラティリティが拡大し、最終的に急落することが多い

---

## パターンの共通注意事項

### ブレイクとダマシの区別

```
ダマシのブレイク（false breakout）が多いパターン:
  対称トライアングル、ウェッジ

対策:
  ① 終値での確定を待つ（ヒゲのブレイクは無視）
  ② 出来高の増加を確認（FXはティック量で代替）
  ③ ブレイク後のリテストを待ってエントリー
  ④ 上位足でのパターン確認（下位足のパターンは信頼性が下がる）
```

### 時間足による信頼性

```
週足 > 日足 > 4H > 1H > 15M
```

下位足のパターンは雑音が多く、ダマシが増える。

### 出来高の役割

FXは出来高データが完全ではないが、ブローカーのティック量を参考にする。
- ブレイクで量が増えていれば本物の可能性が高まる
- 量が減ったままのブレイクはダマシが多い

---

## パターン選択の優先順位

| 優先度 | パターン | 理由 |
|--------|---------|------|
| 高 | ダブルボトム/ダブルトップ | 頻出、機能しやすい |
| 高 | 三尊/逆三尊 | 信頼性が高い反転シグナル |
| 高 | 上昇/下降トライアングル | 方向が明確 |
| 中 | フラッグ/ペナント | 継続パターンとして使いやすい |
| 中 | 下降ウェッジ（買い） | FXでよく見られる |
| 低 | 拡大フォーメーション | 判断が難しい |
| 低 | 対称トライアングル | 方向不明で使いにくい |

---

## まとめ

> チャートパターンは「価格の心理戦の痕跡」。
> フラッグは「勝った側がポジションを積み増す前の休憩」、
> トライアングルは「買いと売りの綱引きの終盤」。
> どのパターンも「意味がわかれば納得できる形」をしている。
> ただし、**全てのパターンは後から見れば綺麗に見える**。
> リアルタイムで判断するには、パターン単独でなく
> トレンドの文脈・水平線・モメンタム指標との合算が不可欠。

## 実例：実チャートベースのトレード例

### 例1: USD/JPY 4H足 — 上昇フラッグで上昇トレンドへの乗り継ぎ（2022年4月）

**状況**  
2022年4月、USD/JPYが125円から131円まで急騰（ポール）した後、数日間の調整（フラッグ）を経て再上昇した局面。

**パターンの形状**
```
ポール（急上昇）: 125.00 → 131.35（4月25日〜28日、約6円上昇）

フラッグ（調整）: 131.35から129.50付近まで緩やかに下落
  期間: 約4日（4月28日〜5月2日）
  形状: 緩やかに右下がりの平行チャンネル
  安値の切り下げは緩やか（急落ではない）

フラッグのブレイク: 5月3日 130.00を上方向に終値で抜ける
→ 上昇継続確認
```

**目標値計算**
```
ポールの長さ: 131.35 - 125.00 = 6.35円
ブレイクポイント: 130.00
目標値: 130.00 + 6.35 = 136.35円
```

| 項目 | 値 |
|------|-----|
| エントリー | 130.20（フラッグ上辺ブレイク確定の次の4H）|
| SL | 129.00（フラッグ下辺の外側）|
| TP | 136.00（ポール等倍）|
| 結果 | 5月下旬に131〜132で一時横ばいの後、6月に135円到達 |
| RR比 | 約1:4.8 |

**ポイント**  
「急騰 → 緩やかな調整 → 継続」のフラッグは上昇の勢いが本物であることを示す。調整が急落なら買い手の撤退を意味するが、緩やかな戻しは「利確しているだけで売り手が本格参入していない」証拠。

### 例2: EUR/USD 日足 — 下降トライアングルが下落継続を示した（2022年6〜7月）

**状況**  
2022年6〜7月、EUR/USDが1.04〜1.05付近で下降トライアングルを形成した後、パリティへ向けて急落した局面。

**パターンの形状**
```
水平な下辺（サポート）: 1.0350〜1.0380付近（何度もテスト）
切り下がる上辺（レジスタンス）: 1.0600 → 1.0500 → 1.0420 と切り下げ

  \   /\  /\  /\
   \ /  \/  \/  \──→ブレイクダウン
    /              \
━━━━━━━━━━━━━━━━━━━━ ← 1.0350の水平サポート

高値が切り下がり、安値は同水準を保つ
→ 売り手が強まっている（弱気パターン）
```

**トレード**
```
2022年7月第2週: 1.0350を日足終値で下抜け
→ 下降トライアングル完成 → ショートエントリー

目標値: 1.0350 - (1.0600 - 1.0350) = 1.0100
（トライアングル最大幅ぶん）
```

| 項目 | 値 |
|------|-----|
| エントリー | 1.0320（下抜け翌日）|
| SL | 1.0450（トライアングル下辺の上）|
| TP① | 1.0100（目標値）|
| TP② | 1.0000（パリティ）|
| 結果 | 翌週にパリティ到達。TP②達成 |
| RR比 | 約1:2.4（TP②まで）|

**ポイント**  
「同じ安値を何度もテストする」ことは、その水準の買い手を少しずつ消耗させていることを意味する。高値は切り下がるのに安値は水平というのは「もうすぐ売り手が買い手を全滅させる」予告であり、ブレイクが来たら大きく動くシグナルでもある。

### 例3: GBP/USD 日足 — 下降ウェッジからの反転で底値買い（2022年9〜10月）

**状況**  
2022年9月のミニ予算ショックで急落したGBP/USDが、10月にかけて下降ウェッジを形成し、そこからV字回復した局面。

**パターンの形状**
```
急落: 9月末 1.0349 の歴史的安値
   ↓
10月: 下降ウェッジ形成
  上辺（急傾斜）: 高値が急速に切り下がる  1.1200 → 1.0800 → 1.0600
  下辺（緩傾斜）: 安値の切り下がりが緩やか 1.0350 → 1.0500 → 1.0550

2本のラインが収束するにつれてボラティリティ低下
→ 「下落の勢いが弱まっている」証拠
```

**ブレイクのシグナル**
```
2022年10月中旬:
  日足で上辺（1.1100付近）を終値で上抜け
  → 下降ウェッジのブレイクアウト（買いシグナル）
  RSI: 底値圏（38付近）で強気ダイバージェンス同時発生
  → ロングエントリー
```

| 項目 | 値 |
|------|-----|
| エントリー | 1.1120（上辺ブレイク確定翌日）|
| SL | 1.0900（ウェッジ上辺の内側）|
| TP① | 1.1600 |
| TP② | 1.2000 |
| 結果 | 11月に1.1650到達（TP①）、2023年に1.2500超え |
| RR比 | 約1:2.3（TP①）|

**ポイント**  
下降ウェッジは「下落の勢いが収縮している」パターン。急落後に出現した場合は特に「売り手の燃料切れ」を意味し、上方向へのブレイクで強い上昇が起きやすい。ウェッジ上辺のブレイクで初めてエントリーし、ウェッジ内に引き返したらカットという明確なルールを作りやすいのもこのパターンの利点。

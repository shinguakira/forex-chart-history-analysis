# チャートパターン集 (Chart Patterns)

フラッグ・ペナント・ウェッジ・トライアングル・カップ&ハンドルなど、
三尊・ダブルトップ以外の主要なチャートパターンをまとめる。

---

## パターンの分類

| 種類 | 意味 | 代表パターン |
|------|------|------------|
| **継続パターン** | トレンドが一休みして再開する | フラッグ、ペナント、対称トライアングル |
| **反転パターン** | トレンドが転換する | ウェッジ（一部）、拡大フォーメーション |
| **どちらにも** | ブレイクの方向によって決まる | 対称トライアングル、ウェッジ |

---

## フラッグ (Flag) ─ 継続パターン

急激な動き（ポール）の後、逆方向に緩やかに押し戻されるパターン。
旗竿（ポール）に旗（フラッグ）が付いた形。

### 形状

```
上昇フラッグ:
        ───────
       /  \ /  \   ← フラッグ（やや下向きのチャンネル）
      /    /    \
     /    /      \──
    /    /
---/  ← ポール（急上昇）
```

```
下降フラッグ:
---\  ← ポール（急下落）
    \    \
     \    \      /──
      \    \    /
       \  / \  /   ← フラッグ（やや上向きのチャンネル）
        ───────
```

### 特性

- フラッグは**トレンド方向と逆向きに緩やかに**推移する（逆方向ならOK）
- ポールの長さが目標値の目安
- **出来高**: ポールで増加 → フラッグで減少 → ブレイクで再増加 が理想

### 目標値

```
目標値 = ブレイクポイント + ポールの長さ
```

### トレード

```
① ポール（急騰/急落）を確認
② フラッグ形成を確認（逆方向のチャンネル）
③ フラッグのブレイクを待つ
④ エントリー
⑤ SL: フラッグの反対辺の外側
⑥ TP: ポールの長さ分
```

---

## ペナント (Pennant) ─ 継続パターン

フラッグと同様にポール+フラッグだが、フラッグ部分が三角形（ペナント）になる。

### 形状

```
上昇ペナント:
       /\
      /  \
     / 収 \
    /  縮  \→→ ブレイクアウト
   /         \
--/  ← ポール  \...(収縮する三角形)
```

### フラッグとの違い

| 比較 | フラッグ | ペナント |
|------|--------|---------|
| フラッグ部分の形 | 平行チャンネル | 収縮する三角形 |
| 継続時間 | 短め | やや短め |
| 出来高パターン | 同じ | 同じ |

## ウェッジ (Wedge) ─ 反転 or 継続

2本の収縮する傾いたトレンドラインの間に価格が挟まれるパターン。

### 上昇ウェッジ（ライジングウェッジ）

```
        /──────  ← 上辺（傾き緩い）
       /    /
      /    /
     /    /
    /    /
   /──── ← 下辺（傾き急）
```

- **逆張りシグナル（下落）**: 上昇しているが収縮している = 買い圧力が徐々に弱まっている
- 上昇トレンド中 → 反転（天井）
- 下降トレンド中の戻り → 継続（戻り売り）

### 下降ウェッジ（フォーリングウェッジ）

```
\──── ← 上辺（傾き急）
 \    \
  \    \
   \    \
    \    \
     \────  ← 下辺（傾き緩い）
```

- **順張りシグナル（上昇）**: 下落しているが収縮している = 売り圧力が弱まっている
- 下降トレンド中 → 反転（底値）
- 上昇トレンド中の押し目 → 継続（押し目買い）

### まとめ

| ウェッジ | トレンド中 | 意味 |
|---------|-----------|------|
| 上昇ウェッジ | 上昇中 | 天井反転の可能性（売り） |
| 上昇ウェッジ | 下落中の戻り | 継続（戻り売り） |
| 下降ウェッジ | 下落中 | 底値反転の可能性（買い） |
| 下降ウェッジ | 上昇中の押し目 | 継続（押し目買い） |

## トライアングル (Triangle)

3種類。方向感が異なる。

### 1. 対称トライアングル（Symmetrical Triangle）

```
   /\ /\ /\
  /  V  V  \──→ どちらにブレイクするか不明
 /          \
/   収縮     \
```

- 高値が切り下がり、安値が切り上がり → 上辺・下辺が収縮
- **ブレイクの方向がわからない** → ブレイクを確認してからエントリー
- 多くの場合、トレンド継続パターンとして機能

### 2. 上昇トライアングル（Ascending Triangle）

```
━━━━━━━━━━━━━━━━ ← 水平な上辺（同じ高値で何度も止まる）
   /\ /\ /\
  /  V  V  V──→ ブレイクアップ（買いシグナル）
```

- 高値は同レベルで押さえられているが、安値は切り上がっている
- 買い手が売り手に着実にプレッシャーをかけている
- **強気パターン**: 上にブレイクしやすい

### 3. 下降トライアングル（Descending Triangle）

```
   /\ /\ /\──→ ブレイクダウン（売りシグナル）
  /  V  V  V
 /          
━━━━━━━━━━━━━━━━ ← 水平な下辺（同じ安値で何度も支えられる）
```

- 安値は同レベルで支えられているが、高値は切り下がっている
- 売り手が買い手を着実に追い詰めている
- **弱気パターン**: 下にブレイクしやすい

### 目標値

```
ブレイクポイント ± トライアングルの最大幅（一番左端の幅）
```

## カップ＆ハンドル (Cup & Handle)

ウィリアム・オニールが提唱した上昇継続パターン。

### 形状

```
        ━━━━━━━━━━━━ ← ネックライン
       /    ハンドル\   /
      /    (/\)     \ /──→ ブレイクアップ
     /     /  \      ∨
    /    (cup)  \
   /              \
  /    U字底       \
 ─────────────────────
```

### 形成プロセス

```
① カップ（U字の底）:
   - 急落後、緩やかに下値を切り上げながら戻ってくる
   - V字（急反発）より U字（緩やか）の方が理想的
   - 期間は数週間〜数ヶ月

② ハンドル:
   - ネックライン付近に戻ってきた後、小さな押し戻し
   - 出来高が減少するのが理想
   - 全体の20〜30%を超えない浅い押し戻し

③ ブレイクアウト:
   - ネックラインを出来高増加とともに抜ける
   - エントリーポイント
```

### 目標値

```
カップの深さ = ネックライン - カップの底値
目標値 = ネックライン + カップの深さ
```

## 拡大フォーメーション（メガフォン）

トライアングルの逆。高値が切り上がり、安値が切り下がる。

```
   /\ /\ /\──→ 拡大
  /  V  V  V
```

- 不確実性・混乱の高まりを示す
- 多くの場合、**天井圏**で見られる（反転パターン）
- ボラティリティが拡大し、最終的に急落することが多い

## パターンの共通注意事項

### ブレイクとダマシの区別

```
ダマシのブレイク（false breakout）が多いパターン:
  対称トライアングル、ウェッジ

対策:
  ① 終値での確定を待つ（ヒゲのブレイクは無視）
  ② 出来高の増加を確認（FXはティック量で代替）
  ③ ブレイク後のリテストを待ってエントリー
  ④ 上位足でのパターン確認（下位足のパターンは信頼性が下がる）
```

### 時間足による信頼性

```
週足 > 日足 > 4H > 1H > 15M
```

下位足のパターンは雑音が多く、ダマシが増える。

### 出来高の役割

FXは出来高データが完全ではないが、ブローカーのティック量を参考にする。
- ブレイクで量が増えていれば本物の可能性が高まる
- 量が減ったままのブレイクはダマシが多い

## パターン選択の優先順位

| 優先度 | パターン | 理由 |
|--------|---------|------|
| 高 | ダブルボトム/ダブルトップ | 頻出、機能しやすい |
| 高 | 三尊/逆三尊 | 信頼性が高い反転シグナル |
| 高 | 上昇/下降トライアングル | 方向が明確 |
| 中 | フラッグ/ペナント | 継続パターンとして使いやすい |
| 中 | 下降ウェッジ（買い） | FXでよく見られる |
| 低 | 拡大フォーメーション | 判断が難しい |
| 低 | 対称トライアングル | 方向不明で使いにくい |

---

## まとめ

> チャートパターンは「価格の心理戦の痕跡」。
> フラッグは「勝った側がポジションを積み増す前の休憩」、
> トライアングルは「買いと売りの綱引きの終盤」。
> どのパターンも「意味がわかれば納得できる形」をしている。
> ただし、**全てのパターンは後から見れば綺麗に見える**。
> リアルタイムで判断するには、パターン単独でなく
> トレンドの文脈・水平線・モメンタム指標との合算が不可欠。

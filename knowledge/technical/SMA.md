# SMA (Simple Moving Average / 単純移動平均)

## 概要

指定した期間の終値を単純平均したもの。価格のノイズを除去して「トレンドの方向」を視覚化する最もシンプルな指標。

---

## 計算式

```
SMA(n) = (P₁ + P₂ + ... + Pₙ) / n
```

- `n` = 期間
- `P` = 各バーの終値（設定次第でHLCの平均なども可）

全期間のデータが等しく扱われる（古いデータも最新データも同じ重み）。

---

## 主要な期間設定

| 期間 | 用途 | 特性 |
|------|------|------|
| 20 | 短期 | ノイズ多め、反応早い |
| 50 | 中期 | バランス型。多くのトレーダーが注目 |
| 100 | 中長期 | 中期トレンドの目安 |
| 200 | 長期 | 最も注目される節目。「200MA」と呼ばれる |

---

## 読み方

### 1. 傾き（トレンド方向）

- 右上がり → 上昇トレンド
- 右下がり → 下降トレンド
- 横ばい → レンジ（方向感なし）

### 2. 価格とMAの位置関係

- 価格 > MA → 強気（买い勢い優勢）
- 価格 < MA → 弱気（売り勢い優勢）
- MAに接触 → サポート/レジスタンスとして機能することがある

### 3. クロス（グランビルの法則）

2本のMAを使う場合：

**ゴールデンクロス（買いシグナル）**
- 短期MA が 長期MA を下から上に抜ける

**デッドクロス（売りシグナル）**
- 短期MA が 長期MA を上から下に抜ける

ただし、**クロスはラグが大きい**（すでに動いた後に発生）ので、エントリーより「確認」として使うほうが実用的。

---

## ラグの問題

SMAの最大の弱点は**遅れ（ラグ）**。

- n期間のSMAは、過去n本の平均なので、現在価格への反応がn/2バー遅れる
- 20SMAは約10バー、200SMAは約100バー遅れるイメージ
- トレンドの転換点を捉えるには遅すぎることが多い

→ 反応速度を上げたい場合はEMAを検討。

---

## フォレックスでの使い方

### ダイナミックS/R（動くサポート・レジスタンス）
価格がMA付近で反発するパターン。特に50MAや200MAは多くの参加者が意識するため「自己成就予言」的に機能しやすい。

```
上昇トレンド中:
価格 → 50MAに押し目 → 反発 → 継続
       ↑ここで買いを検討
```

### 200MAの"地政学"
- 日足の200MAより上 → 長期強気
- 日足の200MAより下 → 長期弱気
- 200MAを明確に上抜けた直後 → 買い需要増加（機関投資家のルールに組み込まれていることも）

### トレンドフィルター
SMAは単独でエントリーするより、「どちらの方向に仕掛けるか」の**フィルター**として使うのが効果的。

```
200MA より上 → 買いシグナルのみ採用
200MA より下 → 売りシグナルのみ採用
```

---

## 限界・注意点

- **レンジ相場では機能しない**: 横ばい中はMAを価格が上下にクロスを繰り返し（ウィッピング）、誤シグナルが増える
- **ラグが大きい**: 遅れて動くため、急反転には対応できない
- **パラメータ依存**: 最適な期間はペアや時間軸によって異なる。過去最適化（カーブフィッティング）に注意
- **価格の歪み**: スパイクや窓（ギャップ）に引っ張られる

---

## 他インジとの組み合わせ

| 組み合わせ | 目的 |
|-----------|------|
| SMA × EMA | トレンド強度の比較 |
| SMA × RSI | トレンド方向 + オーバーソールド/バイ判断 |
| SMA × ボリンジャーバンド | ボリンジャーの中心線がSMAそのもの |
| SMA × MACD | MACDの計算にEMAを使うが、SMAも代替可 |

---

## まとめ

> SMAはシンプルだが「大衆が見ている」という事実が力になる。
> 特に200MAは単なる平均ではなく、**マーケット参加者の集合的な意識**を反映したレベルとして機能する。
> 単体でエントリーするより、「大きな絵」を描くためのツールとして使うのが本来の使い方。

# RSI (Relative Strength Index / 相対力指数)

## 概要

一定期間の**上昇幅の平均**と**下降幅の平均**の比率から、価格の「勢い（モメンタム）」を0〜100のスケールで表すオシレーター。

J・ウェルズ・ワイルダー Jr. が1978年に考案。単に「買われすぎ・売られすぎ」を示すだけでなく、**ダイバージェンス**（価格とRSIの乖離）が最も強力なシグナルになる。

---

## 計算式

```
RS  = 平均上昇幅 / 平均下降幅
RSI = 100 - 100 / (1 + RS)
```

**平均上昇幅・下降幅の計算（ワイルダー式 = EMA的な平滑化）:**

```
1回目: 単純平均（最初のn本）
2回目以降:
  平均上昇幅 = (前回の平均上昇幅 × (n-1) + 今回の上昇幅) / n
  平均下降幅 = (前回の平均下降幅 × (n-1) + 今回の下降幅) / n
```

上昇幅 = 前バーより上なら差額、下なら 0
下降幅 = 前バーより下なら差額（正の値）、上なら 0

---

## 期間設定

| 期間 | 特性 |
|------|------|
| **14**（デフォルト） | 最も広く使われる。ワイルダー推奨 |
| 9 | 短期・スキャルプ向け。感度高くノイズ多め |
| 21 | 中期。滑らか |
| 2〜3 | 極短期・逆張り専用（Connors RSI等） |

---

## 基本の読み方

### 1. 過買い・過売れ水準

| 水準 | 解釈 |
|------|------|
| **70以上** | 買われすぎゾーン（売り検討） |
| **30以下** | 売られすぎゾーン（買い検討） |
| 50 | 中立ライン。上 → 強気、下 → 弱気 |

⚠️ **重要な誤解**:
- 70超 = すぐ売る、ではない
- 強いトレンド中は70〜90台に張り付き続ける
- トレンドに逆らった使い方は損失の源

### 2. 50ラインのブレイク
- 30→50方向に上昇 → 上昇モメンタム回復
- 70→50方向に下落 → 下降モメンタム回復

スイングトレーダーはこの50ライン通過をエントリートリガーにすることも多い。

---

## 最も重要：ダイバージェンス

価格の動きとRSIの動きが**逆方向**になる現象。トレンド転換の早期シグナル。

### 弱気ダイバージェンス（Bearish Divergence）—— 売りシグナル

```
価格:  高値₁  →  高値₂（高値₂ > 高値₁、切り上げ）
RSI:   高値₁  →  高値₂（RSI高値₂ < RSI高値₁、切り下げ）

→ 価格は上昇しているがモメンタムが弱まっている
→ 上昇の勢いが失われつつある
```

### 強気ダイバージェンス（Bullish Divergence）—— 買いシグナル

```
価格:  安値₁  →  安値₂（安値₂ < 安値₁、切り下げ）
RSI:   安値₁  →  安値₂（RSI安値₂ > RSI安値₁、切り上げ）

→ 価格は下落しているがモメンタムが改善している
→ 下落の勢いが失われつつある
```

**ポイント:**
- 70超・30以下のゾーンで発生したダイバージェンスはより信頼性が高い
- 複数の高値/安値で確認できるほど強い（2点より3点）
- 確認が必要: RSIが50を超える（強気D）/ 50を割る（弱気D）まで待つ

---

## ヒドゥン・ダイバージェンス（隠れダイバージェンス）

トレンド継続シグナル。通常のダイバージェンスと逆。

### 強気ヒドゥン（買い）

```
価格: 安値を切り上げ（上昇トレンドの押し目）
RSI: 安値を切り下げ
→ トレンド継続の押し目買いシグナル
```

### 弱気ヒドゥン（売り）

```
価格: 高値を切り下げ（下降トレンドの戻り）
RSI: 高値を切り上げ
→ トレンド継続の戻り売りシグナル
```

---

## フォレックスでの実践的な使い方

### トレンド相場での使い方
過買い・過売れの逆張りは危険。代わりに：
- 上昇トレンド中は RSI が 40〜50 に落ちた場面を押し目として拾う
- 下降トレンド中は RSI が 50〜60 に上がった場面を戻りとして売る

### レンジ相場での使い方
- RSI 30以下で買い、70以上で売りが有効
- ただしレンジブレイク時は逆に火傷

### 組み合わせ例
```
① 日足でトレンド方向を確認（200SMA位置）
② 4H足のRSIでダイバージェンスを探す
③ 1H足でエントリータイミングを取る
```

---

## 限界・注意点

- **絶対的な過買い・過売れではない**: RSI 80でも上がり続けることは普通にある
- **ラグがある**: n期間のデータが必要なため、最初のシグナルは遅れる
- **誤ダイバージェンス**: すべてのダイバージェンスが反転につながるわけではない
- **期間設定への依存**: 期間を変えると全く違う絵になる
- **単独使用は危険**: 必ず価格アクション・水平線・トレンド分析と組み合わせる

---

## まとめ

> RSIの真価は「70超=売り・30以下=買い」という単純なルールにはない。
> 最大の武器は**ダイバージェンス**— 価格が新高値/新安値をつけてもRSIがついてこない時、
> それはモメンタムの枯渇を示しており、転換の前兆になりやすい。
> ただし**確認が必ず必要**で、ダイバージェンスが出ても反転するまでエントリーしない規律が重要。

## 実例：実チャートベースのトレード例

### 例1: USD/JPY 日足 — 弱気ダイバージェンスが151.94の天井を示した（2022年10月）

**状況**  
2022年10月、USD/JPYが1990年以来初めて150円台に乗せた局面。多くの参加者が「まだ上がる」と期待していた中、日足RSIは転換のシグナルを発していた。

**シグナルと判断**
```
高値①: 2022年9月 145.90  RSI(14): 79付近
高値②: 2022年10月 151.94  RSI(14): 72付近

価格: 高値① → 高値②（新高値更新、+6円）
RSI : 79 → 72（切り下げ）
→ 弱気ダイバージェンス確定
```
- 日銀の為替介入警戒（145円で既に介入実績あり）
- 月足ローソクが長い上ヒゲ陰線
- RSIが70台で天井のダイバージェンス

| 項目 | 値 |
|------|-----|
| エントリー | 150.50（日足陰線確定後のショート）|
| SL | 152.50（高値②の上）|
| TP① | 145.00（介入前の水準）|
| TP② | 140.00 |
| 結果 | 介入もあり127円まで下落。TP②大幅超え |
| RR比 | 1:2.5〜10以上（どこで利確したかによる）|

**ポイント**  
「価格が新高値なのにRSIが切り下げ」は教科書通りの弱気D。ここではさらに為替介入という外的要因も重なったが、RSIダイバージェンスだけでも転換シグナルとして有効だった。

---

### 例2: GBP/USD 日足 — 強気ダイバージェンスが歴史的底値を示した（2022年9月）

**状況**  
2022年9月末、英国のミニ予算（大規模減税案）発表でGBP/USDが1985年以来の安値1.0349まで急落。市場は「GBPがさらに下がる」という見方が大勢を占めていた。

**シグナルと判断**
```
安値①: 2022年9月 1.1350前後  RSI: 25付近
安値②: 2022年9月末 1.0349   RSI: 19付近

価格: 安値①→安値②（新安値更新、-1000pips超）
RSI : 25→19（まだ切り下げ。Dはまだ発生していない）

※ その後10月に:
安値③試し: 1.0700付近  RSI: 28付近（安値②より浅い）
→ 価格は安値②より上、RSIは安値②より上
→ 強気ダイバージェンス確定（ダブルボトムとの合流）
```

| 項目 | 値 |
|------|-----|
| エントリー | 1.0850（RSI 50ライン回復後のロング）|
| SL | 1.0600（安値③の下）|
| TP① | 1.1400 |
| TP② | 1.2000 |
| 結果 | 11月に1.1600超え。TP①到達 |
| RR比 | 約1:2.2 |

**ポイント**  
「歴史的な安値圏で強気D」は転換力が強い。ただし安値②の直後ではなく「安値③で価格が前の安値を更新できず、RSIも改善した」という**確認**ができてからエントリーが原則。

### 例3: EUR/USD 4H足 — RSI40ラインが上昇トレンド中の押し目を定義（2023年2月）

**状況**  
2023年1〜2月、EUR/USDが0.97から1.10へ大幅反発したトレンド局面。4H足RSIがトレンド中の「押し目水準」として40ラインを繰り返し使っていた。

**シグナルと判断**
- 上昇トレンド中、4H足RSIが40〜45まで下がるたびに価格が反発
- RSIが70超えで一旦天井 → 40〜45に下がれば押し目として買い
- この区間を3回繰り返した

**具体的な局面（2023年2月初旬）**
```
4H足RSI: 43（押し目）
価格: 1.0700付近（EMA21にタッチ中）
→ 陽線包み足確定
→ ロングエントリー
```

| 項目 | 値 |
|------|-----|
| エントリー | 1.0720（4H陽線確定）|
| SL | 1.0650（直近安値の下）|
| TP | 1.0930（直近高値付近）|
| 結果 | 3日後に1.0920到達 |
| RR比 | 約1:3 |

**ポイント**  
強い上昇トレンド中のRSI「30以下=買い」という通常の逆張りルールは機能しない。トレンド中は「40〜50が押し目水準」になることが多い。これをトレンド中のRSIの特性として覚えておく。

# フィボナッチ (Fibonacci)

## 概要

フィボナッチ数列（1,1,2,3,5,8,13,21...）の比率から導いたレベルで、**価格の押し目・戻りの候補**や**目標値**を算出する手法。自然界の黄金比（1.618）に由来し、マーケット参加者が広く意識するため「自己成就予言」として機能しやすい。

---

## フィボナッチ比率の導出

| 比率 | 計算 | 名称 |
|------|------|------|
| **23.6%** | F(n)/F(n+3) の極限 | 浅い押し目 |
| **38.2%** | 1 - 0.618 | 浅〜中程度の押し目 |
| **50.0%** | 数列由来ではなく経験則 | 中間値 |
| **61.8%** | F(n)/F(n+1) の極限（黄金比の逆数）| **最重要**。黄金比 |
| **78.6%** | √0.618 | 深い押し目 |

---

## リトレースメント（押し目・戻りの候補）

トレンドの「どこまで戻るか」を予測する。

### 引き方

```
上昇トレンドの押し目:
  起点（直近の安値）→ 終点（直近の高値）に引く
  → 各レベルが押し目の候補
  
下降トレンドの戻り:
  起点（直近の高値）→ 終点（直近の安値）に引く
  → 各レベルが戻りの候補
```

**重要**: スイング高値・安値はローソク足の実体ではなくヒゲ先端で取ることが多い（ツール依存）。

### 各レベルの特性

```
23.6% ── 浅い押し目。強いトレンドで止まる。勢いが強い証拠
38.2% ── 標準的な押し目。トレンド継続中によく見られる
50.0% ── 心理的な中間地点。多くのトレーダーが意識
61.8% ── 最重要レベル。「黄金比」として最も機能しやすい
78.6% ── 深い押し目。ここを割るとトレンド転換疑い
```

### 実践的なエントリー判断

```
リトレース中:
  ① フィボレベルに近づく
  ② ローソク足パターン（ピンバー・包み足）を確認
  ③ RSI がダイバージェンス or 過売れ
  ④ 水平線・トレンドラインと重なる（合流）
  → 全部揃えば高確率ゾーン
```

---

## エクステンション（目標値の算出）

押し目からの継続で、**どこまで伸びるか**を予測する。

### 主要なエクステンションレベル

| レベル | 説明 |
|--------|------|
| **127.2%** | √1.618。最初の目標値として使われることが多い |
| **141.4%** | √2 |
| **161.8%** | 黄金比。最も意識される利確・節目 |
| **200.0%** | 直近スイングの2倍 |
| **261.8%** | 1.618² |

### 引き方

```
上昇の波 A→B の押し目 C からの目標値:
  A（起点安値）→ B（高値）→ C（押し目安値）の3点を指定
  → 161.8%などが目標値の候補
```

---

## フィボナッチゾーン（PRZ: Potential Reversal Zone）

複数のフィボレベルが集まる「集積帯」が特に強い。

```
例: 
  61.8% リトレース
  + 200MA
  + 水平線（過去の高値）
  → この価格帯は超強力なS/R
```

複数の根拠が重なる場所を**コンフルエンス（Confluence）**と呼ぶ。
フォレックスで勝ちトレードの多くはコンフルエンスゾーンを活用している。

---

## フィボナッチチャンネル / エクスパンション

トレンドの伸びを等倍・1.618倍などで予測するツール。
エクステンションと似ているが、チャンネルとして描くケース。

---

## フォレックスでの使い方

### 押し目買い（最も基本）

```
1. 日足〜4H で上昇トレンドを確認
2. 直近スイング安値〜高値でフィボを引く
3. 61.8% 付近に価格が落ちてくるのを待つ
4. 1H で押し目確認のエントリーパターンを探す
5. 直近安値の下にストップ
6. 利確は 100%（元の高値）または 161.8% エクステンション
```

### ストップロスの設定
- 61.8% で入った場合 → 78.6% の下にSL
- 78.6% で入った場合 → 100%（起点）の下にSL

### ラウンドナンバーとの組み合わせ
フィボレベルがキリ番（例: 110.00, 1.3000）に近い場合、そのゾーンはさらに機能しやすい。

---

## 主要な失敗パターン

| 状況 | 意味 |
|------|------|
| 23.6% で止まらず 38.2% へ | 特に問題ない。より深い押し目 |
| 61.8% を明確に割り込む | トレンド転換の可能性。ポジション見直し |
| 78.6% を割り込む | 高確率でトレンド転換 |
| どのレベルでも止まらない | エントリーを見送る |

---

## 限界・注意点

- **どのスイングを選ぶかで結果が変わる**: 恣意的になりがち
- **「後付け」になりやすい**: 反転した後で「あそこが61.8%だった」と言えるがリアルタイムでは難しい
- **複数レベルがある**: どれで止まるかはわからない
- **単体では機能しない**: 必ず他の根拠（水平線・パターン・オシレーター）と合わせて使う
- **完璧には機能しない**: レベルを少し超えてから反転（オーバーシュート）することが多い

---

## まとめ

> フィボナッチは「自然の比率」ではなく、**多くのトレーダーが同じ場所を見ている**から機能する。
> 61.8% が特別な理由は数学的な美しさではなく、「機関投資家のモデルに組み込まれている」という
> 現実的な理由のほうが大きい。
> 最大の使い方は単独ではなく「コンフルエンス（複数根拠の集積）」を作ること。

---

## 実例：実チャートベースのトレード例

### 例1: USD/JPY 日足 — 61.8%が急落後の押し目として機能（2023年1〜2月）

**状況**  
2022年10月の高値151.94から2023年1月の安値127.23まで急落したUSD/JPY。その後の上昇局面で、フィボナッチリトレースメントの各レベルが押し目として機能した。

**フィボの引き方**
```
起点（直近安値）: 127.23（2023年1月）
終点（直近高値）: 137.90（2023年3月）

各レベル:
  23.6% → 135.40
  38.2% → 133.82
  50.0% → 132.57
  61.8% → 131.32  ← ここが重要
  78.6% → 129.50
```

**シグナルと判断**
- 4月に価格が調整で下落、61.8%（131.32）付近まで戻る
- 同エリアに200SMAが重なる（コンフルエンス）
- 4H足でRSI40水準まで低下 + 陽線確定

| 項目 | 値 |
|------|-----|
| エントリー | 131.50（61.8%付近でのピンバー確定）|
| SL | 130.00（78.6%の下）|
| TP① | 137.00（前回高値付近）|
| TP② | 140.00（フィボエクステンション127.2%）|
| 結果 | 5月に140円超え。TP②到達 |
| RR比 | 約1:5.7（TP②まで）|

**ポイント**  
61.8%に200SMAが重なった「コンフルエンス」が特に機能した典型例。単独のフィボレベルより複数の根拠が同じ価格帯に集まる場合に信頼性が格段に上がる。

### 例2: EUR/USD 4H足 — 38.2%リトレースで戻り売り（2022年7〜8月）

**状況**  
2022年7〜8月、EUR/USDが下降トレンド中（1.10→1.00方向）。一時的な反発でどこまで戻るかの判断にフィボナッチを使った局面。

**フィボの引き方（下落波への戻り測定）**
```
起点（直近高値）: 1.0615（2022年7月上旬）
終点（直近安値）: 0.9998（2022年7月中旬）

各レベル（戻りの上限候補）:
  23.6% → 1.0144
  38.2% → 1.0234  ← ここで止まった
  50.0% → 1.0307
  61.8% → 1.0379
```

**シグナルと判断**
- 38.2%（1.0234）付近まで反発
- 4H足で200EMAがレジスタンスと重なる（コンフルエンス）
- MACDがゼロラインより下で弱気クロス発生

| 項目 | 値 |
|------|-----|
| エントリー | 1.0220（38.2%タッチ後の4H陰線確定）|
| SL | 1.0320（50%の上）|
| TP① | 0.9900（直近安値更新目標）|
| TP② | 0.9700 |
| 結果 | 9月に0.9700到達。TP②達成 |
| RR比 | 約1:3.2（TP①まで）|

**ポイント**  
下降トレンドでの戻りは38.2%〜50%で終わることが多い。今回は38.2%でEMA200が重なり止まった。下位足での「陰線確定」を待つことで「まだ上がるかも」という迷いを消した。

### 例3: USD/JPY 日足 — エクステンション161.8%が天井の目標値（2022年）

**状況**  
2022年初頭、USD/JPYが115円から上昇を開始。フィボナッチエクステンションで上値目標を事前に算出していた場合、151円台が理論的な目標値として浮かび上がっていた。

**フィボエクステンションの引き方**
```
A（起点安値）: 102.59（2020年3月）
B（高値）:    125.86（2022年3月）
C（押し目）:  126.36（2022年1月、B前の戻り）

161.8%エクステンション → 163.30付近
127.2%エクステンション → 148.40付近
```

**より現実的な短期フィボ**
```
A（2022年1月安値）: 113.50
B（2022年3月高値）: 125.10
C（2022年2月押し目）: 114.40

161.8% → 152.17  ← 実際の高値151.94に近い
```

| 活用方法 | 内容 |
|---------|------|
| 利確の目安 | 161.8%（151〜152円）付近で利益を確保 |
| リスク管理 | 目標値付近でポジションを段階的に縮小 |
| 反転監視 | 161.8%到達後にRSIダイバージェンスを監視 |
| 結果 | 実際に151.94で天井、大幅反転 |

**ポイント**  
「これだけ上がったらどこが目標か」という問いにフィボエクステンションが答える。全ての波がフィボに従うわけではないが、161.8%付近での反転は歴史的に頻繁に見られる。事前に目標を持つことでポジションサイズや利確戦略を明確にできる。

# MACD (Moving Average Convergence Divergence)

## 概要

2本のEMAの差を使って**トレンドの方向・勢い・転換**を可視化するインジケーター。ジェラルド・アペルが1970年代に開発。

「収束（Convergence）」と「発散（Divergence）」という名前の通り、2本のEMAが近づいたり離れたりする動きそのものが分析対象。モメンタム系とトレンド系の両方の性質を持つ。

---

## 構成要素と計算式

```
MACDライン = EMA(12) - EMA(26)
シグナルライン = MACDラインのEMA(9)
ヒストグラム = MACDライン - シグナルライン
```

**デフォルトパラメータ: (12, 26, 9)**

| 要素 | 計算 | 色（一般的）| 役割 |
|------|------|------------|------|
| MACDライン | EMA12 - EMA26 | 青 | メインライン（速い） |
| シグナルライン | MACDのEMA9 | オレンジ/赤 | トリガーライン（遅い） |
| ヒストグラム | MACD - シグナル | 棒グラフ（緑/赤）| 両者の差を可視化 |

---

## MACDラインが示すもの

EMA12とEMA26の差 = 「短期の勢いが長期の勢いを上回っているか」

```
MACD > 0  → EMA12 > EMA26 → 短期MAが上 → 上昇モメンタム
MACD < 0  → EMA12 < EMA26 → 短期MAが下 → 下降モメンタム
MACD = 0  → 2本のEMAが交差している点
```

MACDラインのゼロクロスは、実質的に**EMAのゴールデン/デッドクロス**と同じタイミング。

---

## 基本シグナル

### 1. シグナルクロス（最も頻繁に使われる）

**強気クロス（買い）**
```
MACDライン が シグナルラインを 下から上に突き抜ける
```

**弱気クロス（売り）**
```
MACDライン が シグナルラインを 上から下に突き抜ける
```

⚠️ ゼロライン付近のクロスより、**ゼロからある程度離れた位置**でのクロスのほうが信頼性が高い。

### 2. ゼロラインクロス（トレンド確認）

```
0 を上抜け → 上昇トレンド確認（遅め）
0 を下抜け → 下降トレンド確認（遅め）
```

エントリーには遅すぎることが多いが、**トレンドフィルター**として有効。

### 3. ヒストグラムの変化（最速のシグナル）

ヒストグラムはMACDとシグナルの差なので、**クロスより1〜2バー早く転換を示す**。

```
ヒストグラムが縮小し始める → モメンタムの減衰
ヒストグラムがゼロを超える → クロス完成
```

プロは「ヒストグラムが山/谷を作った後に縮小し始めた」タイミングをエントリー根拠にする。

---

## ダイバージェンス（最も重要）

RSI同様、価格とMACDの方向が逆になる現象。**MACDのヒストグラムで見るのが最も見やすい**。

### 弱気ダイバージェンス（売りシグナル）

```
価格: 高値を切り上げ
MACDヒストグラム: 山が切り下げ（モメンタムが弱まっている）

→ 上昇の勢いが衰えており、反転下落の可能性
```

### 強気ダイバージェンス（買いシグナル）

```
価格: 安値を切り下げ
MACDヒストグラム: 谷が切り上げ（モメンタムが改善している）

→ 下落の勢いが衰えており、反転上昇の可能性
```

**実践的なポイント:**
- ヒストグラムではなくMACDラインで見る人も多い（どちらでも可）
- 日足〜週足で発生したダイバージェンスのほうが信頼性高い
- 価格アクション（ピンバー、包み足等）と重なると強い

## フォレックスでの使い方

### タイムフレーム別推奨

| TF | パラメータ | 特性 |
|----|-----------|------|
| 日足・週足 | (12,26,9) 標準 | 長期トレンド把握 |
| 4H | (12,26,9) or (8,17,9) | スイングエントリー |
| 1H | (5,13,1) などタイト | デイトレ。ノイズ増 |
| 15M以下 | 標準設定でも可 | スキャルプ。誤シグナル多発 |

### トレンド相場での使い方
```
1. 日足MACD がゼロより上 → 買いバイアス
2. 4H でシグナルクロス（買い）が発生したらエントリー
3. 日足MACDがゼロを割ったらポジション解消
```

### レンジ相場での使い方
レンジではMACDは機能しにくい（連続してクロスが発生し誤シグナルだらけ）。
→ **ADXやボリンジャーバンドの収縮でレンジを先に判断してからMACDを使う**

---

## パラメータのカスタマイズ

| 目的 | 短期EMA | 長期EMA | シグナルEMA |
|------|---------|---------|------------|
| 標準（デフォルト） | 12 | 26 | 9 |
| より敏感 | 8 | 17 | 9 |
| よりスムーズ | 19 | 39 | 9 |
| 長期フィルター | 50 | 100 | 20 |

**基本的には標準(12,26,9)を使い続けることを推奨**。カスタマイズすると過去最適化のリスクが上がる。

---

## 限界・注意点

- **ラグが大きい**: 3つのEMAを使っているため、反応が遅い
- **レンジでは機能しない**: 誤シグナルが多発する
- **絶対値に意味がない**: MACDは0を中心としたオシレーターだが、ペアや時間軸によって振れ幅が違う。他のペアと数値比較はできない
- **トリプルスクリーン推奨**: 1つの時間軸だけで使うと精度が落ちる

---

## まとめ

> MACDは「2本のEMAの関係」を3つの視点（MACDライン、シグナル、ヒストグラム）で見せてくれるツール。
> シグナルクロスは遅いが**わかりやすい**。ヒストグラムの縮小は**早いがノイズが多い**。
> 最も強力なのは**ダイバージェンス**— 価格が新高値/安値を取る一方でMACDが追随しない時、
> それはトレンドの燃料切れを示す最強の警告信号。

## 実例：実チャートベースのトレード例

### 例1: USD/JPY 日足 — MACDヒストグラムの弱気Dが天井を先行検知（2022年9〜10月）

**状況**  
2022年9〜10月にかけてUSD/JPYが145→151.94と上昇した局面。価格は新高値を更新し続けていたが、日足MACDヒストグラムは「山が縮小している」という警告を発していた。

**シグナルと判断**
```
山①（9月）: 価格 145.90  MACDヒストグラム山: 約+1.20
山②（10月）: 価格 151.94  MACDヒストグラム山: 約+0.65

価格は新高値（+6円）なのにヒストグラムは半分以下に縮小
→ 弱気ダイバージェンス（ヒストグラムで確認）
```
- ヒストグラムがゼロに近づき始めた時点でモメンタム枯渇の予告
- MACDラインがシグナルラインを下抜けした日が「確定」

| 項目 | 値 |
|------|-----|
| エントリー | 150.00（MACDデッドクロス確定日）|
| SL | 152.50 |
| TP | 145.00（直近の介入水準）|
| 結果 | 127円まで下落。利確ポイントは個人差あり |
| RR比 | 最低1:2以上 |

**ポイント**  
ヒストグラムのダイバージェンスはMACDラインのクロスより1〜2週間早くシグナルが出る。「ヒストグラムが縮小しながら価格が新高値」という状況を見逃さないことが重要。

---

### 例2: EUR/USD 4H足 — MACDゼロラインクロスでトレンド転換を確認（2022年11月）

**状況**  
2022年9月に0.9536の安値をつけたEUR/USDが反発を始めた。MACDのゼロラインクロスが「下落トレンド終了・上昇トレンド開始」を確認するタイミングになった。

**シグナルと判断**
```
ステップ①: 4H足でMACDライン > シグナルライン（クロス発生）
ステップ②: MACDライン > 0（ゼロライン越え、0.9900付近で発生）
→ 下落トレンド終了の構造的確認

ゼロライン越えの価格帯: 1.0000付近
→ ここで確認できた参加者がロングに転換
```

| 項目 | 値 |
|------|-----|
| エントリー | 1.0050（4H足でゼロライン越え確定の翌足）|
| SL | 0.9800（直近の押し安値の下）|
| TP① | 1.0500 |
| TP② | 1.1000 |
| 結果 | 2023年2月に1.1000到達。TP②達成 |
| RR比 | 1:3.8（TP①まで）、1:7以上（TP②まで）|

**ポイント**  
ゼロラインクロスは遅いが「トレンド転換の事実確認」として機能する。シグナルクロスだけでエントリーするより、ゼロラインも超えてから動くことで「ダマシ」が大幅に減る。

---

### 例3: AUD/USD 日足 — MACDシグナルクロス連続で押し目買いの機会（2023年1〜3月）

**状況**  
2022年10月にAUD/USDが0.6170の安値をつけ、2023年初に0.71台まで反発したトレンド。日足でMACDの強気クロスが発生するたびに押し目として買い場を提供した。

**シグナルと判断**
- 日足MACDゼロラインより上で推移（上昇バイアス継続）
- 価格の押し目のたびにMACDがゼロ付近まで下がってシグナルクロス
- これを3回繰り返した（2023年1月・2月・3月）

**2023年2月の局面**
```
価格が0.6850まで押し目
MACDヒストグラム: ゼロをわずかに下回った後に反転
MACDライン: シグナルラインを下から上に抜ける（強気クロス）
→ ロングエントリー
```

| 項目 | 値 |
|------|-----|
| エントリー | 0.6870（強気クロス確定翌足）|
| SL | 0.6770（直近安値の下）|
| TP | 0.7100（直近高値付近）|
| 結果 | 0.7050で利確（ほぼTP達成）|
| RR比 | 約1:2.3 |

**ポイント**  
ゼロライン付近での強気クロスは「押し目の終了確認」として使える。ただしゼロを大きく下回った状態でのクロスは、下位トレンドへの転換の可能性があるため要注意。

# ダブルトップ・ダブルボトム (Double Top / Double Bottom)

## 概要

**同じ価格帯を2度試して失敗した**ことを示す反転パターン。三尊より形成頻度が高く、日常的によく見られる。

- **ダブルトップ（M字天井）**: 上昇トレンドの終焉 → 下落転換
- **ダブルボトム（W底）**: 下降トレンドの終焉 → 上昇転換

---

## ダブルトップ

### 形状

```
  頂点₁      頂点₂
   /\          /\
  /  \        /  \
 /    \      /    \
/      \    /      \
         \/
      ━━━━━━━━━━━ ← ネックライン（谷の安値）
         ↓
      下落トレンドへ
```

### 形成プロセス

```
① 上昇トレンドの頂点₁: 一旦高値をつけて下落
② ネックライン（谷）: 売り圧力で一旦下落するが、まだトレンド転換と断言できない
③ 頂点₂: 頂点₁付近まで反発するが、更新できない（または微かに超えた後失速）
   → 「2度目も上に行けなかった」= 買い手の限界
④ ネックラインブレイク: パターン完成。売りシグナル
```

### 頂点₂の特徴

| 状況 | 意味 |
|------|------|
| 頂点₂ < 頂点₁ | 弱いダブルトップ。買い手が完全に力を失っている |
| 頂点₂ ≈ 頂点₁ | 標準的なダブルトップ |
| 頂点₂ > 頂点₁（わずか） | 「3段抜け」型。頂点₁を超えて買いを巻き込んでから失速。より強烈な天井 |

---

## ダブルボトム（W底）

### 形状

```
      ネックライン（山の高値）
      ━━━━━━━━━━━ ← 
      /\
     /  \      /
    /    \    /
   /      \  /
  /        \/
底値₁      底値₂
```

### 形成プロセス

```
① 下落トレンドの底値₁: 急落後にいったん反発
② ネックライン（山）: 反発するが続かず再下落
③ 底値₂: 底値₁付近まで再下落するが更に割れない
   → 「2度目も下に行けなかった」= 売り手の限界
④ ネックラインブレイク: パターン完成。買いシグナル
```

---

## 目標値の計算

```
ダブルトップ:
  目標値 = ネックライン - (頂点₁ - ネックライン)

ダブルボトム:
  目標値 = ネックライン + (ネックライン - 底値₁)

例（ダブルボトム）:
  底値: 108.00
  ネックライン: 111.00
  距離: 111.00 - 108.00 = 3.00
  目標値: 111.00 + 3.00 = 114.00
```

---

## 三尊との違い

| 比較 | ダブルトップ | 三尊 |
|------|------------|------|
| 山の数 | 2つ | 3つ |
| 形成期間 | 短め | 長め |
| モメンタムの証拠 | シンプル | より明確（頭が最高値、右肩で弱い） |
| 出現頻度 | 多い | 少ない |
| 信頼性 | やや低め | やや高め |

---

## ダブルトップ/ボトムの品質評価

### 良いパターンの条件

```
✓ 2つの頂点（または底値）がほぼ同じ高さ（±3%程度）
✓ 2つの頂点間に十分な距離がある（少なくとも数本のバー）
✓ ネックラインが明確な水平線になっている
✓ RSI がダイバージェンスを形成している
✓ 出来高が1つ目より2つ目で減少している（三尊同様）
```

### 悪いパターン（ダマシが多い）

```
✗ 2つの頂点間の距離が短すぎる（2〜3本しかない）
✗ ネックラインが斜めに傾いている
✗ 形成期間が異なる（1個目は2週間、2個目は1週間等）
```

## エントリー方法

### 方法1: ネックラインブレイクでエントリー

```
ネックラインを終値で抜けた瞬間にエントリー
SL: 直近の頂点₂（ダブルトップ）または底値₂（ダブルボトム）の外側
TP: 目標値計算 or 次の主要S/R
```

### 方法2: リテストを待つ（推奨）

```
ブレイク確認
  ↓
旧ネックラインまで引き戻し
  ↓
そこで反発するローソク足パターンを確認
  ↓
エントリー（SL は引き戻しの反対側）
```

## アダム＆イブ型

ダブルボトムの形状による分類。ジャック・シャーガーが分類。

| タイプ | 形状 | 特性 |
|--------|------|------|
| アダム＆アダム | 両方 V字（鋭い安値） | 普通 |
| アダム＆イブ | 1つ目 V字、2つ目 U字（丸い） | やや信頼性高め |
| イブ＆アダム | 1つ目 U字、2つ目 V字 | 一般的 |
| イブ＆イブ | 両方 U字（丸い） | 最も信頼性高め。緩やかな転換 |

---

## RSI・MACDとの組み合わせ

```
ダブルトップ + 弱気ダイバージェンス:
  頂点₁ < 頂点₂ （価格は同レベルまたは高値更新）
  RSI頂点₁ > RSI頂点₂ （RSIは切り下げ）
  → 買いモメンタム喪失の強い証拠

ダブルボトム + 強気ダイバージェンス:
  底値₂ ≈ 底値₁ または ≤ 底値₁
  RSI底値₂ > RSI底値₁ （RSIは切り上げ）
  → 売りモメンタム喪失の証拠
```

---

## フォレックスでの使い方

- **日足のダブルトップ/ボトム** は特に信頼性が高い
- ネックラインがラウンドナンバーと重なっていると強い
- 4H 足でパターンを確認、1H 足でエントリータイミングを取るのが一般的

---

## 限界・注意点

- **頂点の高さが全く同じことはほぼない**: ±3〜5% の範囲で見る
- **見え方が主観的**: 「これはダブルトップか、それとも三尊の右肩形成中か」の判断が難しい
- **ネックラインブレイクがダマシになることがある**: リテストを待つことで精度が上がる
- **目標値はあくまで参考**: 途中の強いS/Rで止まることが多い

---

## まとめ

> ダブルトップ・ダブルボトムのシンプルな真実:
> 「同じ価格帯を2度試して失敗した = その価格帯での需給が転換した」。
> 単純なパターンだからこそ多くの参加者が意識し、ネックラインブレイク後に
> 自己成就予言的に動く傾向がある。
> **ネックラインの位置と、ダイバージェンスの有無**がトレードの核心。

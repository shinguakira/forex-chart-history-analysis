# ダブルトップ・ダブルボトム (Double Top / Double Bottom)

## 概要

**同じ価格帯を2度試して失敗した**ことを示す反転パターン。三尊より形成頻度が高く、日常的によく見られる。

- **ダブルトップ（M字天井）**: 上昇トレンドの終焉 → 下落転換
- **ダブルボトム（W底）**: 下降トレンドの終焉 → 上昇転換

---

## ダブルトップ

### 形状

```
  頂点₁      頂点₂
   /\          /\
  /  \        /  \
 /    \      /    \
/      \    /      \
         \/
      ━━━━━━━━━━━ ← ネックライン（谷の安値）
         ↓
      下落トレンドへ
```

### 形成プロセス

```
① 上昇トレンドの頂点₁: 一旦高値をつけて下落
② ネックライン（谷）: 売り圧力で一旦下落するが、まだトレンド転換と断言できない
③ 頂点₂: 頂点₁付近まで反発するが、更新できない（または微かに超えた後失速）
   → 「2度目も上に行けなかった」= 買い手の限界
④ ネックラインブレイク: パターン完成。売りシグナル
```

### 頂点₂の特徴

| 状況 | 意味 |
|------|------|
| 頂点₂ < 頂点₁ | 弱いダブルトップ。買い手が完全に力を失っている |
| 頂点₂ ≈ 頂点₁ | 標準的なダブルトップ |
| 頂点₂ > 頂点₁（わずか） | 「3段抜け」型。頂点₁を超えて買いを巻き込んでから失速。より強烈な天井 |

---

## ダブルボトム（W底）

### 形状

```
      ネックライン（山の高値）
      ━━━━━━━━━━━ ← 
      /\
     /  \      /
    /    \    /
   /      \  /
  /        \/
底値₁      底値₂
```

### 形成プロセス

```
① 下落トレンドの底値₁: 急落後にいったん反発
② ネックライン（山）: 反発するが続かず再下落
③ 底値₂: 底値₁付近まで再下落するが更に割れない
   → 「2度目も下に行けなかった」= 売り手の限界
④ ネックラインブレイク: パターン完成。買いシグナル
```

---

## 目標値の計算

```
ダブルトップ:
  目標値 = ネックライン - (頂点₁ - ネックライン)

ダブルボトム:
  目標値 = ネックライン + (ネックライン - 底値₁)

例（ダブルボトム）:
  底値: 108.00
  ネックライン: 111.00
  距離: 111.00 - 108.00 = 3.00
  目標値: 111.00 + 3.00 = 114.00
```

---

## 三尊との違い

| 比較 | ダブルトップ | 三尊 |
|------|------------|------|
| 山の数 | 2つ | 3つ |
| 形成期間 | 短め | 長め |
| モメンタムの証拠 | シンプル | より明確（頭が最高値、右肩で弱い） |
| 出現頻度 | 多い | 少ない |
| 信頼性 | やや低め | やや高め |

---

## ダブルトップ/ボトムの品質評価

### 良いパターンの条件

```
✓ 2つの頂点（または底値）がほぼ同じ高さ（±3%程度）
✓ 2つの頂点間に十分な距離がある（少なくとも数本のバー）
✓ ネックラインが明確な水平線になっている
✓ RSI がダイバージェンスを形成している
✓ 出来高が1つ目より2つ目で減少している（三尊同様）
```

### 悪いパターン（ダマシが多い）

```
✗ 2つの頂点間の距離が短すぎる（2〜3本しかない）
✗ ネックラインが斜めに傾いている
✗ 形成期間が異なる（1個目は2週間、2個目は1週間等）
```

---

## エントリー方法

### 方法1: ネックラインブレイクでエントリー

```
ネックラインを終値で抜けた瞬間にエントリー
SL: 直近の頂点₂（ダブルトップ）または底値₂（ダブルボトム）の外側
TP: 目標値計算 or 次の主要S/R
```

### 方法2: リテストを待つ（推奨）

```
ブレイク確認
  ↓
旧ネックラインまで引き戻し
  ↓
そこで反発するローソク足パターンを確認
  ↓
エントリー（SL は引き戻しの反対側）
```

## アダム＆イブ型

ダブルボトムの形状による分類。ジャック・シャーガーが分類。

| タイプ | 形状 | 特性 |
|--------|------|------|
| アダム＆アダム | 両方 V字（鋭い安値） | 普通 |
| アダム＆イブ | 1つ目 V字、2つ目 U字（丸い） | やや信頼性高め |
| イブ＆アダム | 1つ目 U字、2つ目 V字 | 一般的 |
| イブ＆イブ | 両方 U字（丸い） | 最も信頼性高め。緩やかな転換 |

---

## RSI・MACDとの組み合わせ

```
ダブルトップ + 弱気ダイバージェンス:
  頂点₁ < 頂点₂ （価格は同レベルまたは高値更新）
  RSI頂点₁ > RSI頂点₂ （RSIは切り下げ）
  → 買いモメンタム喪失の強い証拠

ダブルボトム + 強気ダイバージェンス:
  底値₂ ≈ 底値₁ または ≤ 底値₁
  RSI底値₂ > RSI底値₁ （RSIは切り上げ）
  → 売りモメンタム喪失の証拠
```

---

## フォレックスでの使い方

- **日足のダブルトップ/ボトム** は特に信頼性が高い
- ネックラインがラウンドナンバーと重なっていると強い
- 4H 足でパターンを確認、1H 足でエントリータイミングを取るのが一般的

---

## 限界・注意点

- **頂点の高さが全く同じことはほぼない**: ±3〜5% の範囲で見る
- **見え方が主観的**: 「これはダブルトップか、それとも三尊の右肩形成中か」の判断が難しい
- **ネックラインブレイクがダマシになることがある**: リテストを待つことで精度が上がる
- **目標値はあくまで参考**: 途中の強いS/Rで止まることが多い

---

## まとめ

> ダブルトップ・ダブルボトムのシンプルな真実:
> 「同じ価格帯を2度試して失敗した = その価格帯での需給が転換した」。
> 単純なパターンだからこそ多くの参加者が意識し、ネックラインブレイク後に
> 自己成就予言的に動く傾向がある。
> **ネックラインの位置と、ダイバージェンスの有無**がトレードの核心。

## 実例：実チャートベースのトレード例

### 例1: USD/JPY 週足 — 151円台のダブルトップが円高転換を示した（2022・2023年）

**状況**  
2022年10月の高値151.94と2023年10〜11月の高値151.71が、ほぼ同じ価格帯（151〜152円）でのダブルトップを形成した。日米金利差のピークアウト観測と重なった。

**パターンの形状**
```
高値①: 2022年10月 151.94（日銀介入で急落）
谷  : 2023年1月  127.23（ネックライン候補だが遠すぎる）

→ 中期でのダブルトップとして考えると難しいが、
  週足レベルで151〜152円の「二重天井ゾーン」として機能

高値②: 2023年11月 151.71
→ 1円以内での一致 → ダブルトップ確認
→ RSI: 高値①時72 → 高値②時65 → 弱気ダイバージェンス

ネックライン（より現実的な短期設定）:
  高値②形成時の直前安値: 148.00付近
```

**トレード**
```
2023年11月末: 148.00（ネックライン）を日足終値で割る
→ ショートエントリー

目標値: 148.00 - (151.71 - 148.00) = 144.29
```

| 項目 | 値 |
|------|-----|
| エントリー | 147.80（ネックライン割れ翌日）|
| SL | 149.50（直近高値の上）|
| TP | 144.00 |
| 結果 | 12月に141円台まで下落。TP達成 |
| RR比 | 約1:2.2 |

**ポイント**  
「まったく同じ価格（151円台）で2回弾き返された」という事実は、その水準に大量の売り注文があることを意味する。RSIダイバージェンスとのセットで確信度が上がった。

### 例2: EUR/USD 日足 — W底（ダブルボトム）が歴史的安値からの反転を確認（2022年9〜11月）

**状況**  
2022年9月28日にEUR/USDが0.9536の安値をつけた後、10月中旬にも0.9630付近まで再下落。このW底からの上昇が2023年にかけての大幅回復の起点となった。

**パターンの形状**
```
安値①: 2022年9月28日  0.9536（40年ぶりの安値）
ネックライン（谷後の山）: 0.9800〜0.9850付近

安値②: 2022年10月13日 0.9630
  ← 安値①より高い（94pips浅い）
  ← RSI: 安値①時20.5 → 安値②時24.8 → 強気ダイバージェンス

→ W底（ダブルボトム）確定条件が揃った
```

**トレード**
```
2022年10月下旬:
  ネックライン（0.9850）を日足終値で上抜け
  → ロングエントリー

目標値: 0.9850 + (0.9850 - 0.9536) = 1.0164
```

| 項目 | 値 |
|------|-----|
| エントリー | 0.9870（ネックラインブレイク翌日）|
| SL | 0.9750（安値②の下）|
| TP① | 1.0000（パリティ。心理的節目）|
| TP② | 1.0164（目標値計算）|
| 結果 | 11月に1.0350到達。TP②大幅超え |
| RR比 | 1:1.1（TP①）、1:2.5（TP②）|

**ポイント**  
「歴史的な安値でのW底 + RSI強気ダイバージェンス」は非常に強力な組み合わせ。安値②が安値①より浅いという「需給のシフト」が核心であり、ネックラインブレイクがその確認になった。

### 例3: GBP/JPY 4H足 — ダブルトップが短期での利益機会（2023年7月）

**状況**  
2023年7月、GBP/JPYが183〜184円台でダブルトップを形成。短期のポジショントレードで利益が取れた典型例。

**パターンの形状**
```
高値①: 2023年7月13日  184.00付近
安値（谷）: 181.50付近（ネックライン）
高値②: 2023年7月24日  183.80付近（高値①より20pips低い）

RSI:
  高値①: 71
  高値②: 65 → 弱気ダイバージェンス
  
形成期間: 約11日（4H足レベルとしては十分）
```

**トレード**
```
高値②形成後、価格が181.50のネックラインを下抜け
4H足終値確認 → ショートエントリー

目標値: 181.50 - (184.00 - 181.50) = 179.00
```

| 項目 | 値 |
|------|-----|
| エントリー | 181.20（ネックライン下抜け確定の次の4H）|
| SL | 182.50（高値②より上）|
| TP | 179.00（目標値）|
| 結果 | 179.40まで下落。TP達成 |
| RR比 | 約1:1.7 |

**ポイント**  
4H足でも教科書通りのダブルトップが形成される。形成期間が短いほどパターンの精度が下がるが、RR比1.5以上でネックライン割れ確定後に入れば再現性は十分ある。弱気ダイバージェンスが「品質保証」として機能した。

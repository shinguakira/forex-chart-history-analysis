# トレンドライン・チャンネル (Trendline & Channel)

## 概要

安値（または高値）を結んだ斜めのライン。**動く水平線**として機能し、トレンドの方向・強さ・継続/転換の判断に使う。水平線が「横の壁」なら、トレンドラインは「斜めの壁」。

---

## 基本：3種類のトレンドライン

### 1. 上昇トレンドライン（サポートライン）
安値を結ぶ斜め上向きのライン。

```
         /ヒゲ
        /
  /ヒゲ/
 /
/ヒゲ
↑
安値₁ 安値₂ 安値₃ を結ぶ
```

- 価格がラインに触れて反発 → 上昇継続のシグナル
- ラインを下抜け → トレンド転換の警告

### 2. 下降トレンドライン（レジスタンスライン）
高値を結ぶ斜め下向きのライン。

```
\ヒゲ
 \
  \ヒゲ
   \
    \ヒゲ
↑
高値₁ 高値₂ 高値₃ を結ぶ
```

### 3. 水平トレンドライン
レンジ相場の上下限。（→ SupportResistance.md 参照）

---

## 有効なトレンドラインの条件

### タッチ回数
```
2点 → まだ「有効かもしれない」
3点 → 有効と判断できる
4点以上 → 非常に信頼性が高い
```

最低でも**3点のタッチ**で引くことを推奨。2点だけでは「引こうと思えばどこにでも引ける」ため。

### 角度
```
傾きが急すぎる（70°以上）
  → 長く続かない。近いうちにブレイクされやすい
  
傾きが浅すぎる（10°以下）
  → 水平線に近く、トレンドラインとしての意味が薄い

30〜45°程度が最も機能しやすい
```

### 時間足
上位足（週足・日足）のトレンドラインほど強力。
下位足のトレンドラインは上位足の確認に使う。

---

## チャンネルライン（平行チャンネル）

トレンドラインに**平行な線**を反対側に引いたもの。

```
上昇チャンネル:
  下辺 = 安値を結ぶトレンドライン（サポート）
  上辺 = 高値を結ぶ平行線（レジスタンス）

         ━━━━━━━━━━━━ ← 上辺（レジスタンス）
        /
       /  /
      /  /
─────────────────── ← 下辺（サポート）
```

### チャンネル内のトレード

**理想的な使い方:**
```
下辺タッチ → 買い（サポートで拾う）
上辺タッチ → 利確 or 逆張り売り
```

**注意**: チャンネルを割ったら上辺が抵抗になる（ロール）。

### チャンネルの種類

| 種類 | 傾き | 意味 |
|------|------|------|
| 上昇チャンネル | 右上がり | 上昇トレンド中 |
| 下降チャンネル | 右下がり | 下降トレンド中 |
| 水平チャンネル | 横 | レンジ相場 |

---

## ブレイクアウトとリテスト

### ブレイクの確認方法

```
❌ ヒゲがトレンドラインを超えただけ → ダマシの可能性高い
✓  終値がトレンドラインを明確に超えた → ブレイク濃厚
✓✓ 終値がトレンドラインを超え + 出来高増加 → より信頼性高い
```

### リテスト（最重要）

ブレイク後に旧トレンドラインまで戻り、今度は反発する動き。

```
上昇トレンドラインをブレイクダウン:
  旧サポートライン → 今度はレジスタンスとして機能
  → 戻りで売るエントリー機会

下降トレンドラインをブレイクアップ:
  旧レジスタンスライン → 今度はサポートとして機能
  → 押し目で買うエントリー機会
```

---

## トレンドラインの引き方の実践

### ヒゲで引くか・実体で引くか

**ヒゲで引く:**
- 最大の値幅まで試されたポイントを使う
- よりタッチ回数が増える可能性
- ヒゲをかすめるようなラインが多くなる

**実体で引く:**
- 終値（確定値）でのS/Rを重視
- タッチ回数は減るが、ラインとしてより「確実」

**推奨:** 複数のタッチが確認できるならヒゲ先端。タッチ数が少なければ実体を優先。

### フォレックスでよく使うトレンドライン

- **4H〜日足の主要なトレンドライン**: スイングトレードの根拠
- **前回高値/安値を起点にしたライン**: 自然発生的に機能しやすい
- **V字の反発起点を結んだライン**: 急騰・急落後のトレンドライン

---

## インターナル・トレンドライン

価格のジグザグの「本体」を結ぶライン（ヒゲをかすめる外側でなく、価格の密度が高い部分を通るライン）。

機関投資家はこちらをより重視することがある。
実体の集積部分を目視でフィットさせる感覚的な作業。

---

## 複数のトレンドラインと「ファン」

| 名前 | 内容 |
|------|------|
| フィボナッチファン | 起点から扇状に角度違いのラインを引く |
| ギャン角 | ギャン理論に基づく固定角度（45°等）のライン |
| スピードライン | 主要な上昇幅の1/3, 2/3 地点を結ぶ |

---

## 限界・注意点

- **引く場所が主観的**: 同じチャートでも人によって違う線を引く
- **最初の2点は誰でも引ける**: 3点目で有効性が確認される前にトレードしない
- **急すぎるトレンドラインは長続きしない**: 必ずいつか緩やかなラインに移行する
- **ブレイクのダマシ**: ラインを一時的に割ってすぐ戻ることがある（特に週末明け・重要指標）
- **どのラインも永遠には続かない**: いつかはブレイクされる。そのブレイクこそがトレードチャンス

---

## まとめ

> トレンドラインは「トレンドが生きているかどうか」のバロメーター。
> 重要なのは「ラインが割れた瞬間」 ——
> 長く機能していたトレンドラインのブレイクは大きな相場転換のシグナルになりやすい。
> ただしブレイクとダマシの区別は慎重に。**終値確定 + リテスト確認**が最も信頼性の高い手順。

## 実例：実チャートベースのトレード例

### 例1: USD/JPY 週足 — 9ヶ月続いた上昇トレンドラインのブレイク（2022年10月〜2023年1月）

**状況**  
2022年1月（115円）から10月（151.94円）まで続いた上昇トレンド。週足で安値を結ぶトレンドラインが綺麗に引け、日銀の為替介入後にこのラインを割り込んだ。

**トレンドラインの形成**
```
起点①: 2022年1月安値 113.50
起点②: 2022年3月安値 121.30
起点③: 2022年7月安値 131.40
→ 3点を結んだ上昇トレンドライン（傾き 約+5円/月）

9〜10月: 介入で急落するたびに「ラインに近づいているか？」を確認
  → まだラインより上だったため、上昇トレンド継続と判断
```

**ブレイクのシグナル**
```
2022年10月: 151.94高値（日銀再介入）
    ↓
10月末〜11月: 急落でトレンドラインに接近
    ↓
11月第2週: 週足終値でトレンドラインを下抜け（140円付近）
    → 9ヶ月ぶりのブレイク確定
    → トレンド転換の警告

リテスト（11月下旬〜12月）: 140円付近まで反発
    → 旧サポートがレジスタンスとして機能
    → ショートエントリーの機会
```

| 項目 | 値 |
|------|-----|
| エントリー | 141.00（リテスト後の週足陰線確定）|
| SL | 143.50（トレンドラインの上）|
| TP | 131.00（下値目標）|
| 結果 | 2023年1月に127円まで下落。TP大幅超え |
| RR比 | 約1:4 |

**ポイント**  
長期間（9ヶ月）機能したトレンドラインのブレイクは大きな転換の証拠。ブレイク直後より「リテストを待ってから」エントリーしたほうが、SLを小さくして確信を持てる。

### 例2: EUR/USD 日足 — 下降トレンドラインブレイクが反転の起点（2022年11月）

**状況**  
2022年2月から9月まで続いたEUR/USDの下降トレンド。日足の高値を結ぶ下降トレンドラインが半年以上機能し、11月にブレイクした。

**トレンドラインの形成**
```
起点①: 2022年2月高値 1.1495
起点②: 2022年4月高値 1.0937
起点③: 2022年8月高値 1.0368
→ 3点を結んだ下降トレンドライン（傾き 約-0.05/月）
```

**ブレイクのシグナル**
```
2022年11月初旬:
  米CPI下振れ（インフレ鈍化）でドル急落
  EUR/USDが急上昇
  日足終値で下降トレンドラインを上抜け（1.0050付近）
  翌日もラインより上を維持 → ブレイク確定

リテスト（11月中旬）:
  1.0050付近まで一時的に引き戻し
  そこで陽線確定 → 旧レジスタンスがサポートに
  → ロングエントリーの機会
```

| 項目 | 値 |
|------|-----|
| エントリー | 1.0080（リテスト後の日足陽線確定）|
| SL | 0.9950（トレンドラインの下）|
| TP① | 1.0500 |
| TP② | 1.1000 |
| 結果 | 2023年2月に1.1000到達。TP②達成 |
| RR比 | 約1:3.2（TP①）|

**ポイント**  
「重要なマクロイベント（CPI）でブレイク」という状況は、その後の動きが強くなりやすい。ブレイクの「材料」と「テクニカル」が合致した時にエントリーするのが理想。

### 例3: GBP/USD 4H足 — 下降チャンネル内のバウンストレード（2022年9〜10月）

**状況**  
2022年9月のミニ予算ショック後、GBP/USDが急落。その後の10月の回復局面で、4H足で明確な下降チャンネルが形成された。チャンネル内でのバウンストレードが有効だった。

**チャンネルの形成**
```
下辺（サポート）: 安値を結んだ下降ライン（1.0350から右上がり）
上辺（レジスタンス）: 高値を結んだ平行ライン

10月のレンジ:
  下辺: 1.0950〜1.1100付近（時間とともに上昇）
  上辺: 1.1400〜1.1600付近
```

**バウンストレード**
```
価格が下辺（1.1000付近）に接近
  ↓
4H足でRSI 38（押し目ゾーン）
  ↓
下ヒゲのピンバー確定
  → 下辺バウンスのロングエントリー

上辺（1.1450付近）で利確
```

| 項目 | 値 |
|------|-----|
| エントリー | 1.1050（下辺タッチ後の4H陽線確定）|
| SL | 1.0950（下辺の外側）|
| TP | 1.1450（上辺付近）|
| 結果 | 1.1400で利確（ほぼTP達成）|
| RR比 | 約1:3.5 |

**ポイント**  
チャンネルはS/Rが「斜めに動く版」。上辺でショート、下辺でロングという単純な繰り返しが、チャンネルが有効な間は機能し続ける。ただし「チャンネルが有効かどうか」の判断（タッチ回数・対称性）が先決。

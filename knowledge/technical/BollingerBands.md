# ボリンジャーバンド (Bollinger Bands)

## 概要

移動平均線（SMA）の上下に**標準偏差（σ）**を使ったバンドを描き、**価格の「正常な値動き範囲」**を可視化するインジケーター。ジョン・ボリンジャーが1980年代に開発。

統計学的に、正規分布に従うデータであれば：
- ±1σ 内に収まる確率: **約68%**
- ±2σ 内に収まる確率: **約95%**
- ±3σ 内に収まる確率: **約99.7%**

この性質を活用して「バンドの外に出た = 異常な動き = いつかは戻る」という発想のインジケーター。

---

## 計算式

```
中心線（ミドルバンド）= SMA(n)
上バンド（+2σ）    = SMA(n) + k × σ(n)
下バンド（−2σ）    = SMA(n) − k × σ(n)
```

**σ（標準偏差）の計算:**
```
σ = √( Σ(Pᵢ - SMA)² / n )
```

**デフォルトパラメータ: n=20, k=2**

| パラメータ | 意味 | 変えると |
|-----------|------|----------|
| n（期間） | バンドの基準となるSMAの期間 | 大きくすると滑らか・反応遅い |
| k（倍率） | 標準偏差の何倍かでバンド幅を決める | 大きくするとバンド幅が広がり逸脱が減る |

---

## 構成要素の役割

### ミドルバンド（中心線）
- 20SMA そのもの
- トレンド方向を示す
- 上方傾斜 → 上昇トレンド、下方傾斜 → 下降トレンド

### アッパーバンド（+2σ）
- 通常の上限ライン
- 価格がここに触れる → 過剰な上昇圧力
- ただし**ウォークすることがある**（後述）

### ロワーバンド（−2σ）
- 通常の下限ライン
- 価格がここに触れる → 過剰な下落圧力

---

## バンドウィズ（帯幅）が重要

```
バンドウィズ = (アッパー - ロワー) / ミドル × 100
```

### スクイーズ（収縮）
バンドが狭まる = ボラティリティが低下している = **大きな動きの前触れ**

```
スクイーズ
  ↓
ブレイクアウト（どちらに動くかはわからない）
  ↓
大きなトレンド発生
```

**スクイーズの確認方法:**
- バンド幅が過去数ヶ月で最も狭い
- ミドルバンドが横ばい
- ローソク足がバンド内でちょこちょこ動いている

### エクスパンション（拡大）
バンドが広がる = ボラティリティが高まっている = **トレンドが発生中**

---

## 読み方：3つのパターン

### パターン1：ミーンリバージョン（逆張り）

レンジ相場で機能。バンドタッチで反発を狙う。

```
価格がロワーバンドにタッチ
  → ミドルバンドへの回帰を狙って買い
  → 利確目標: ミドルバンド または アッパーバンド

価格がアッパーバンドにタッチ
  → ミドルバンドへの回帰を狙って売り
  → 利確目標: ミドルバンド または ロワーバンド
```

⚠️ トレンド相場では機能しない。バンドをウォークして逆張りで大きな損失になる。

### パターン2：バンドウォーク（順張り）

強いトレンド相場で発生。バンドを「歩く」ように推移する。

```
上昇トレンド: 価格がアッパーバンドを沿いながら上昇し続ける
  → アッパーバンドタッチで売ろうとすると大損
  → ミドルバンドへの押し目で買い継続が正解

下降トレンド: 価格がロワーバンドを沿いながら下落し続ける
  → ロワーバンドタッチで買おうとすると大損
```

**バンドウォークの見分け方:**
- ミドルバンドが一方向に傾いている
- 価格がバンドの片側（上 or 下）で推移を続けている
- バンドが拡大している

### パターン3：スクイーズブレイク（ブレイクアウト狙い）

スクイーズ後のブレイクを捉える。

```
スクイーズを確認
  ↓
バンドを明確に抜ける方向にエントリー
  ↓
エクスパンションで乗る
  ↓
バンドが縮小し始めたら利確
```

**注意**: ダマシが多い。バンドを一旦抜けて戻ってくることも多い。
確認として「バンドを抜けたローソク足の終値」を待つのが基本。

## W底・M天井との組み合わせ（ボリンジャーの推奨手法）

ジョン・ボリンジャー自身が推奨する手法。

### 強気のW底

```
1回目: 価格がロワーバンドを下回る（恐怖の第1波）
2回目: 価格がロワーバンドの内側で反発（第2安値）
  ※第2安値 > 第1安値（切り上げ）
  ※第2安値時のRSI/MACDも切り上げ（ダイバージェンス確認）

→ 第2安値からロング
→ ミドルバンドを抜けたら本格上昇確認
```

### 弱気のM天井

```
1回目: 価格がアッパーバンドを上回る
2回目: アッパーバンドの内側で上値が重くなる
  ※第2高値 < 第1高値（切り下げ）
  ※第2高値時のRSI/MACDも切り下げ

→ 第2高値からショート
```

---

## フォレックスでの使い方

### スキャルプ（短期）
- 1M〜15Mで±2σタッチを逆張り
- バンドウォークに注意。ミドルバンドの傾きでフィルタリング

### デイトレ・スイング
- 4H〜日足でスクイーズを探す
- ブレイクアウト後のエクスパンションを狙う

### 長期フィルター
- 週足のボリンジャー位置で「今どこにいるか」を把握
- 週足アッパー付近で短期売りを探すなど

---

## よくある間違い

| 間違い | 正解 |
|--------|------|
| バンドタッチ = 必ず反転 | トレンド中はタッチしても方向継続 |
| スクイーズ = 上昇 | スクイーズはどちらに動くかわからない |
| バンドを出たら即エントリー | ローソク足の確定を待つ |
| ミドルバンドは単なる参考線 | ミドルは重要なS/Rとして機能する |

---

## 他のインジとの組み合わせ

| 組み合わせ | 目的 |
|-----------|------|
| ボリンジャー + RSI | タッチ + ダイバージェンスで逆張りの精度UP |
| ボリンジャー + MACD | スクイーズブレイクの方向確認 |
| ボリンジャー + 水平線 | バンドと水平線が重なる位置は特に強いS/R |
| ボリンジャー + 出来高 | ブレイクアウト時に出来高増加 → 信頼性UP |

---

## まとめ

> ボリンジャーバンドは「価格の統計的な正常範囲」を描く。
> 逆張りの道具として使いやすいが、**トレンド相場ではむしろ順張りの道具**になる。
> バンドウィズ（帯幅）の変化 —— スクイーズとエクスパンション —— を読むことが
> 単なるバンドタッチ以上に重要。ボラティリティの「低→高」の変化が次の大きな動きを予告する。

---

## 実例：実チャートベースのトレード例

### 例1: USD/JPY 日足 — バンドウォークで円安トレンドに乗る（2022年3〜6月）

**状況**  
2022年3〜6月、USD/JPYが115円から135円まで急上昇した局面。日足ボリンジャーバンドが完全に拡大しながら、価格がアッパーバンドを沿って「ウォーク」し続けた。

**シグナルと判断**
```
3月: スクイーズ解消 → アッパーバンドを上抜け
   → バンドウォーク開始の確認

アッパーバンドに沿って上昇:
  3月末: 125円（アッパー付近）
  4月末: 131円（アッパー付近）
  5月末: 130円（一時ミドルに接近、押し目）
  6月末: 137円（アッパー付近）
```
- ミドルバンド（20SMA）が急角度で右上がり → トレンド継続の確認
- アッパーバンドタッチで売ると大損するパターンの典型

**トレード（スクイーズブレイク後のエントリー）**

| 項目 | 値 |
|------|-----|
| エントリー | 126.00（アッパーバンド上抜けの翌日）|
| SL | 123.50（ミドルバンドを終値で割った場合）|
| TP① | 130.00（心理的節目）|
| TP② | 135.00 |
| 結果 | 6月に135円超え。TP②達成 |
| RR比 | 約1:3.6（TP②まで）|

**ポイント**  
アッパーバンドタッチで逆張りしたくなる心理が最大の罠。バンドウォーク中はアッパーバンドを売るのではなく、ミドルバンド（20SMA）への押し目を買うのが正解。ミドルを終値で割ったら撤退する規律も重要。

---

### 例2: EUR/USD 週足 — スクイーズ後のブレイクで大きなトレンドを捉える（2022年6〜9月）

**状況**  
2022年6月、EUR/USDが1.04付近で数週間膠着（スクイーズ）した後、パリティ（1.0000）に向けて急落したケース。週足ボリンジャーのスクイーズが「嵐の前の静けさ」だった。

**シグナルと判断**
```
5〜6月: バンド幅が過去数ヶ月で最も狭い（スクイーズ）
    価格: 1.04〜1.07のレンジ
    ミドルバンドが横ばい

→ スクイーズ確認
→ どちらに動くかを待つ

7月第1週: ロワーバンドを終値で下抜け
→ 下方向へのブレイクアウト確定
→ ショートエントリー
```

| 項目 | 値 |
|------|-----|
| エントリー | 1.0300（ロワーバンド下抜け翌週寄り）|
| SL | 1.0550（ミドルバンドの上）|
| TP① | 1.0000（パリティ）|
| TP② | 0.9600 |
| 結果 | 9月に0.9536到達。TP②達成 |
| RR比 | 1:1.2（TP①）、1:2.9（TP②）|

**ポイント**  
「スクイーズ → ブレイクアウト → エクスパンション」は理論通りに動いたケース。週足レベルのスクイーズは月単位の大きなトレンドの起点になりやすい。方向は事前にわからないが、「どちらかに大きく動く準備が整っている」という認識が重要。

### 例3: GBP/USD 4H足 — ロワーバンドW底からの反転（2022年10月）

**状況**  
2022年9月末にGBP/USDが1.0349で底打ちした後、10月に回復する局面。4H足ボリンジャーバンドのロワーバンドでW底（2度目の安値がより浅い）が形成された。

**シグナルと判断**
```
底値①（9月末）: 1.0349  → ロワーバンド大幅下抜け
                          ヒゲがバンドの外に出た後引ける

急反発 → 1.0900付近まで戻る

底値②（10月初）: 1.0650  → ロワーバンドの内側で止まる
                           （底値①より150pips浅い）
                           RSIも強気ダイバージェンス同時発生

→ ロワーバンドW底 + RSI強気D = 高確率買いシグナル
```

| 項目 | 値 |
|------|-----|
| エントリー | 1.0750（4H足でミドルバンドを上抜けた確認）|
| SL | 1.0580（底値②の下）|
| TP① | 1.1200 |
| TP② | 1.1500 |
| 結果 | 11月に1.1650到達。TP②達成 |
| RR比 | 約1:4.4（TP②まで）|

**ポイント**  
「1回目がバンド外・2回目がバンド内」という位置関係がW底確認の重要な条件。2回目の安値がバンドの内側に収まっているということは、売りモメンタムが明らかに弱まっている証拠。ミドルバンドを上抜けた確認を待つことで、早期エントリーの失敗を防げる。

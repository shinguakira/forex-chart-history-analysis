# AI Predictions  (route: `/predictions`)

## What it's for

Have Claude generate concrete trade predictions (direction + entry / stop loss / take profit) for selected currency pairs, then later validate them against what actually happened in the market. Lets you track AI accuracy over time, even compare different models.

## Layout

- **Header** — page title, "API configured" indicator, Settings button.
- **Generation panel** — pair selector + count input + Generate button.
- **Generation progress** — phased status (Fetching market data → Streaming → Parsing).
- **Model performance card** — per-model W/L counts and accuracy, when predictions exist.
- **Filter bar** — status tabs, pair / model dropdowns, date range, Validate-All button.
- **Filtered stats line** — total shown / W / L / Pending / win rate.
- **Predictions grid** — card per prediction (responsive 1/2/3 columns).

## Controls & actions

### Header

- **Settings** — opens the AI provider dialog.

### Generation panel

- **Pair multi-select** — toggle each pair on/off (USD/JPY, EUR/USD, etc.).
- **Count input** — number of predictions to generate (1-50). Leave empty for `auto` (model decides).
- **Generate** — runs the AI; progresses through fetch → stream → parse phases.
- **Cancel** (during run) — aborts.

### Filters

- **Status tabs** — `All` / `Pending` / `Win` / `Loss` (clicking switches the visible set).
- **Pair dropdown** — `All Pairs` or specific pair (only shows pairs that have at least one prediction).
- **Model dropdown** — `All Models` or a specific model (e.g., `claude-sonnet-4-...`).
- **Date range** — `From` / `To` date inputs filter by prediction creation date.
- **Validate All (N)** button — appears only when there are pending predictions; runs validation on every pending one in the current view.

### Per-prediction card

Each card shows: pair name, direction badge (long/short), status badge (pending/win/loss/expired), entry / stop loss / take profit prices, timeframe, model name, creation date.

- **Validate** (pending only) — fetches market data after the creation time and checks if SL or TP was hit, marks the prediction `win`/`loss`/`expired`.
- **Delete** — removes the prediction.
- **Validation result** (after validation) — pips gained/lost, exit price, exit time.

## Workflows

**Generate fresh ideas** — Pick 2–3 pairs you trade. Leave count empty (or set to 5). Click Generate. Wait for the cards to populate.

**Track AI performance** — Wait a few hours/days, then come back and click "Validate All (N)" to resolve pending predictions. The Model Performance card updates to show win rates across all your generated predictions.

**Compare models** — Generate predictions over weeks, then filter by model in the Model dropdown to compare each model's accuracy.

## Data shown

- **Predictions** — generated by Claude with structured output: direction, entry / SL / TP prices, timeframe, model used, creation timestamp.
- **Validation result** — pips, exit price, exit time, status.
- **Stats** — wins, losses, pending count, accuracy %, plus per-model breakdown.

## Configuration

- Requires Claude API key (see [README — AI Settings](./README.md#common-ai-settings)).

## Storage / persistence

- **Predictions** — `data/predictions.json` (loaded/saved via `/api/predictions` Vite plugin).
- **Provider choice** — `localStorage` via Zustand `ai-store`.

## Limits / gotchas

- Validation uses a fixed holding period (1 day) — predictions that haven't hit SL or TP within that window are marked `expired`.
- Validation requires market data covering the post-creation period; very recent predictions may not yet have enough data to validate.
- Generation can hit Yahoo Finance limits if many pairs × deep history are requested at once. Reduce count or pair selection if you see fetch errors.
- Empty Pair / Model dropdowns appear once you have predictions for those values.
